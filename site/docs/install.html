DocumentationGet started

Install and update

Install Kiln on macOS or Windows, open your first workspace, keep the app up to date and choose its language.

Install Kiln with one command or download it from GitHub Releases. Kiln then keeps itself up to date, and updates leave your running terminals alone.

Requirements

Platform Requirement
macOS macOS 11 or later on an Apple Silicon Mac. Builds are notarized.
Windows Windows 11 on x64 or ARM64. Builds are not code-signed yet.

Intel Mac and Linux builds are not currently provided. Windows 10 is not tested.

Install on macOS

Use the install script

Run this in Terminal:

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | sh

The script downloads the latest stable Apple Silicon app and checks the release checksum, Developer ID signature, bundle identity and Apple notarization before installing it in /Applications. If Kiln is already installed, the script leaves it in place; use Kiln → Check for Updates to upgrade instead.

To install somewhere else, set KILN_INSTALL_DIR:

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | KILN_INSTALL_DIR="$HOME/Applications" sh

Download the app

  1. Download the Apple Silicon archive from GitHub Releases.
  2. Extract it.
  3. Move Kiln.app into Applications before you open it.

Install on Windows

Use the PowerShell script

Run this in PowerShell:

irm https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.ps1 | iex

The script picks the x64 or ARM64 archive for your machine, checks the release checksum and the archive's paths and version, and then:

  • installs Kiln into %LOCALAPPDATA%\Programs\Kiln,
  • adds a Kiln shortcut to the Start menu,
  • adds the bin folder to your user PATH, for the kiln command.

Set KILN_INSTALL_DIR to choose another folder. An existing installation is left in place.

Download the archive

You can also download the archive for your architecture from GitHub Releases.

Note Windows builds are not code-signed yet. The install script's download does not trigger SmartScreen, but an archive downloaded with a browser may. Choose More info → Run anyway only for archives from the Releases page.

First launch

  1. Open Kiln from Applications or the Start menu.
  2. Create a workspace with the + button in the workspace sidebar (⌘N on macOS). Give it a name and choose your project folder.
  3. Use the terminal directly, or choose New Task, type a request, pick an agent and start.

The folder can be a single repository or a parent folder that contains several repositories. See Workspaces and tasks for how workspaces, tasks and splits fit together.

On Windows, starting Kiln again while it is running brings the existing window forward and opens the folder you gave it there.

Install the tools you use

Kiln runs the agent and GitHub command-line tools you already have. It does not bundle them or include a subscription. Install and sign in to the ones you use:

Tool Used for
Claude Code (claude) Claude tasks
Codex (codex) Codex tasks
Antigravity (agy) Antigravity tasks. Install it with Google's installer.
gh GitHub features

Kiln looks for agy in your PATH, ~/.local/bin, /opt/homebrew/bin and /usr/local/bin. On Windows, Claude Code and Codex run as native Windows programs and keep their data in %USERPROFILE%\.codex and %USERPROFILE%\.claude.

You can sign in to Claude Code and Codex accounts from Settings → Accounts, and to Antigravity on macOS from Settings → Accounts → Antigravity. On Windows, sign in to Antigravity by running agy in a terminal. See Accounts. To check installed CLI versions or update them, open Settings → Accounts → CLI updates; see Conversations and updates.

Update Kiln

Updates keep your running terminal sessions intact.

macOS

Kiln checks for updates automatically and installs them through the Sparkle update dialog. To check yourself, choose Kiln → Check for Updates, or use the update control in Settings → About. You can turn off automatic checks in Settings.

Windows

Kiln checks for updates once a day. To check yourself, open Settings → About → Check for Updates, then choose Install and Restart. Kiln verifies that the downloaded archive matches the release signing key before it replaces any files. Running terminals keep running.

Tip On macOS 15 and later, if a command that reaches your local network fails in a panel that was open before the update, open a new terminal panel and retry it there. See Local network access on macOS.

Choose a language

Open Settings → Appearance → Language and choose English, Korean, Japanese or Simplified Chinese. The change applies immediately and is saved for the next launch.

Only Kiln's own interface changes. Terminal output, filenames, code, commit messages and agent requests keep their original contents. Installations from earlier versions stay in Korean until you choose a language.

문서시작하기

설치와 업데이트

macOS나 Windows에 Kiln을 설치하고, 첫 워크스페이스를 열고, 앱을 최신 상태로 유지하고, 언어를 고릅니다.

Kiln은 명령 한 줄로 설치하거나 GitHub Releases에서 내려받을 수 있습니다. 설치한 뒤에는 Kiln이 알아서 업데이트하며, 업데이트해도 실행 중인 터미널은 그대로입니다.

요구 사항

플랫폼 요구 사항
macOS Apple Silicon Mac, macOS 11 이상. 빌드는 공증(notarization)을 거칩니다.
Windows x64 또는 ARM64 기반 Windows 11. 빌드는 아직 코드 서명이 되어 있지 않습니다.

Intel Mac과 Linux용 빌드는 현재 제공하지 않습니다. Windows 10에서는 테스트하지 않았습니다.

macOS에 설치하기

설치 스크립트로 설치

터미널에서 다음 명령을 실행합니다.

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | sh

스크립트는 최신 안정 버전의 Apple Silicon 앱을 내려받은 뒤 릴리스 체크섬, Developer ID 서명, 번들 식별 정보, Apple 공증을 확인하고 /Applications에 설치합니다. Kiln이 이미 설치되어 있으면 기존 설치는 건드리지 않습니다. 이때 업그레이드하려면 Kiln → 업데이트 확인을 사용하세요.

다른 위치에 설치하려면 KILN_INSTALL_DIR을 지정합니다.

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | KILN_INSTALL_DIR="$HOME/Applications" sh

앱 직접 내려받기

  1. GitHub Releases에서 Apple Silicon용 압축 파일을 내려받습니다.
  2. 압축을 풉니다.
  3. 앱을 열기 전에 Kiln.app을 응용 프로그램(Applications) 폴더로 옮깁니다.

Windows에 설치하기

PowerShell 스크립트로 설치

PowerShell에서 다음 명령을 실행합니다.

irm https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.ps1 | iex

스크립트는 컴퓨터에 맞는 x64 또는 ARM64 압축 파일을 고르고, 릴리스 체크섬과 압축 파일의 경로·버전을 확인한 다음 아래 작업을 합니다.

  • %LOCALAPPDATA%\Programs\Kiln에 Kiln을 설치합니다.
  • 시작 메뉴에 Kiln 바로 가기를 만듭니다.
  • kiln 명령을 쓸 수 있도록 bin 폴더를 사용자 PATH에 추가합니다.

다른 폴더에 설치하려면 KILN_INSTALL_DIR을 지정하세요. 이미 설치되어 있으면 기존 설치를 그대로 둡니다.

압축 파일 직접 내려받기

GitHub Releases에서 아키텍처에 맞는 압축 파일을 직접 내려받아도 됩니다.

참고 Windows 빌드는 아직 코드 서명이 되어 있지 않습니다. 설치 스크립트로 내려받으면 SmartScreen 경고가 뜨지 않지만, 브라우저로 내려받은 압축 파일에서는 뜰 수 있습니다. 추가 정보 → 실행(More info → Run anyway)은 Releases 페이지에서 받은 압축 파일일 때만 선택하세요.

처음 실행하기

  1. 응용 프로그램 폴더나 시작 메뉴에서 Kiln을 엽니다.
  2. 워크스페이스 사이드바의 + 버튼(macOS에서는 ⌘N)으로 워크스페이스를 만듭니다. 이름을 정하고 프로젝트 폴더를 선택합니다.
  3. 터미널을 바로 쓰거나, 새 작업을 선택해 요청을 입력하고 에이전트를 골라 시작합니다.

폴더는 저장소 하나여도 되고, 여러 저장소를 담은 상위 폴더여도 됩니다. 워크스페이스, 작업, 분할 화면이 어떻게 맞물리는지는 워크스페이스와 작업에서 설명합니다.

Windows에서는 Kiln이 실행 중일 때 다시 실행하면 기존 창이 앞으로 나오고, 넘겨준 폴더를 그 창에서 엽니다.

사용할 도구 설치하기

Kiln은 이미 설치된 에이전트 CLI와 GitHub CLI를 실행합니다. 이 도구들은 Kiln에 포함되어 있지 않고, 구독도 포함되어 있지 않습니다. 사용할 도구를 설치하고 로그인하세요.

도구 용도
Claude Code (claude) Claude 작업
Codex (codex) Codex 작업
Antigravity (agy) Antigravity 작업. Google 설치 프로그램으로 설치합니다.
gh GitHub 기능

Kiln은 PATH, ~/.local/bin, /opt/homebrew/bin, /usr/local/bin에서 agy를 찾습니다. Windows에서 Claude Code와 Codex는 네이티브 Windows 프로그램으로 실행되며, 데이터는 %USERPROFILE%\.codex와 %USERPROFILE%\.claude에 저장합니다.

Claude Code와 Codex 계정은 설정 → 계정에서, macOS의 Antigravity는 설정 → 계정 → Antigravity에서 로그인할 수 있습니다. Windows에서는 터미널에서 agy를 실행해 Antigravity에 로그인합니다. 자세한 내용은 계정을 참고하세요. 설치된 CLI 버전을 확인하거나 업데이트하려면 설정 → 계정 → CLI 업데이트를 여세요. 대화와 업데이트에서 자세히 설명합니다.

Kiln 업데이트

업데이트해도 실행 중인 터미널 세션은 그대로 유지됩니다.

macOS

Kiln은 업데이트를 자동으로 확인하고 Sparkle 업데이트 대화상자로 설치합니다. 직접 확인하려면 Kiln → 업데이트 확인을 선택하거나 설정 → 앱 정보의 업데이트 항목을 사용하세요. 자동 확인은 설정에서 끌 수 있습니다.

Windows

Kiln은 하루에 한 번 업데이트를 확인합니다. 직접 확인하려면 설정 → 앱 정보 → 업데이트 확인을 연 다음 설치하고 다시 시작을 선택합니다. Kiln은 파일을 교체하기 전에 내려받은 압축 파일이 릴리스 서명 키와 맞는지 검증합니다. 실행 중인 터미널은 계속 실행됩니다.

팁 macOS 15 이상에서, 업데이트 전부터 열려 있던 패널에서 로컬 네트워크에 접근하는 명령이 실패하면 새 터미널 패널을 열고 다시 실행하세요. macOS의 로컬 네트워크 접근을 참고하세요.

언어 선택하기

설정 → 모양 → 언어를 열고 영어, 한국어, 일본어, 중국어 간체 중 하나를 고릅니다. 변경 사항은 바로 적용되고, 다음에 실행할 때도 유지됩니다.

바뀌는 것은 Kiln 자체의 인터페이스뿐입니다. 터미널 출력, 파일 이름, 코드, 커밋 메시지, 에이전트 요청은 원래 내용 그대로입니다. 이전 버전에서 설치했다면 언어를 고르기 전까지 한국어로 표시됩니다.

ドキュメントはじめに

インストールとアップデート

macOS と Windows への Kiln のインストール、最初のワークスペースの作成、アップデート、表示言語の設定について説明します。

Kiln はコマンド 1 つでインストールできます。GitHub Releases からダウンロードしてもかまいません。インストール後は Kiln が自動でアップデートされ、実行中のターミナルはアップデートの影響を受けません。

動作環境

プラットフォーム 要件
macOS Apple Silicon 搭載 Mac の macOS 11 以降。ビルドは Apple の公証（notarization）済みです。
Windows x64 または ARM64 の Windows 11。ビルドはまだコード署名されていません。

Intel Mac 版と Linux 版は現在提供していません。Windows 10 での動作は検証していません。

macOS へのインストール

インストールスクリプトを使う

ターミナルで次のコマンドを実行します。

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | sh

スクリプトは最新の安定版 Apple Silicon アプリをダウンロードし、リリースのチェックサム、Developer ID 署名、バンドルの識別情報、Apple の公証を確認してから /Applications にインストールします。Kiln がすでにインストールされている場合、スクリプトは既存のアプリに手を加えません。アップグレードには Kiln → アップデートを確認… を使ってください。

別の場所にインストールするには KILN_INSTALL_DIR を指定します。

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | KILN_INSTALL_DIR="$HOME/Applications" sh

アプリをダウンロードする

  1. GitHub Releases から Apple Silicon 用のアーカイブをダウンロードします。
  2. アーカイブを展開します。
  3. Kiln.app をアプリケーションフォルダーに移動してから開きます。

Windows へのインストール

PowerShell スクリプトを使う

PowerShell で次のコマンドを実行します。

irm https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.ps1 | iex

スクリプトはマシンに合った x64 または ARM64 のアーカイブを選び、リリースのチェックサムと、アーカイブ内のパスおよびバージョンを確認したうえで、次の処理を行います。

  • Kiln を %LOCALAPPDATA%\Programs\Kiln にインストールします。
  • スタートメニューに Kiln のショートカットを追加します。
  • kiln コマンドを使えるように、bin フォルダーをユーザーの PATH に追加します。

別のフォルダーにインストールするには KILN_INSTALL_DIR を指定します。既存のインストールがある場合は、そのまま残します。

アーカイブをダウンロードする

お使いのアーキテクチャ用のアーカイブを GitHub Releases からダウンロードすることもできます。

注意 Windows 版のビルドはまだコード署名されていません。インストールスクリプトによるダウンロードでは SmartScreen は表示されませんが、ブラウザーでダウンロードしたアーカイブでは表示される場合があります。詳細情報 (More info) → 実行 (Run anyway) を選ぶのは、Releases ページから入手したアーカイブだけにしてください。

初回起動

  1. アプリケーションフォルダーまたはスタートメニューから Kiln を開きます。
  2. ワークスペースのサイドバーにある + ボタン（macOS では ⌘N）でワークスペースを作成します。名前を付け、プロジェクトのフォルダーを選んでください。
  3. ターミナルをそのまま使うか、新しい作業を選んでリクエストを入力し、エージェントを選んで開始します。

フォルダーには、1 つのリポジトリも、複数のリポジトリを含む親フォルダーも指定できます。ワークスペース、作業、分割の関係についてはワークスペースと作業を参照してください。

Windows では、Kiln の実行中にもう一度 Kiln を起動すると既存のウィンドウが前面に表示され、渡したフォルダーがそのウィンドウで開きます。

使うツールをインストールする

Kiln は、手元にインストールされているエージェントと GitHub のコマンドラインツールをそのまま実行します。これらのツールは同梱しておらず、サブスクリプションも含まれていません。使うツールをインストールし、ログインしておいてください。

ツール 用途
Claude Code（claude） Claude の作業
Codex（codex） Codex の作業
Antigravity（agy） Antigravity の作業。Google のインストーラーでインストールします。
gh GitHub の機能

Kiln は agy を PATH、~/.local/bin、/opt/homebrew/bin、/usr/local/bin から探します。Windows では、Claude Code と Codex はネイティブの Windows プログラムとして動作し、データを %USERPROFILE%\.codex と %USERPROFILE%\.claude に保存します。

Claude Code と Codex のアカウントには設定 → アカウントから、macOS の Antigravity には設定 → アカウント → Antigravity からログインできます。Windows では、ターミナルで agy を実行して Antigravity にログインします。詳しくはアカウントを参照してください。インストール済みの CLI のバージョンを確認したりアップデートしたりするには、設定 → アカウント → CLI 更新を開きます。詳しくは会話とアップデートを参照してください。

Kiln をアップデートする

アップデートしても、実行中のターミナルセッションはそのまま保たれます。

macOS

Kiln は自動でアップデートを確認し、Sparkle のアップデートダイアログからインストールします。手動で確認するには、Kiln → アップデートを確認… を選ぶか、設定 → このアプリについてにあるアップデートの項目を使います。アップデートの自動確認は設定でオフにできます。

Windows

Kiln は 1 日に 1 回アップデートを確認します。手動で確認するには設定 → このアプリについて → アップデートを確認… を開き、インストールして再起動を選びます。Kiln は、ダウンロードしたアーカイブがリリースの署名鍵と一致することを確かめてから、ファイルを置き換えます。実行中のターミナルはそのまま動き続けます。

ヒント macOS 15 以降では、アップデート前から開いていたパネルでローカルネットワークに接続するコマンドが失敗することがあります。その場合は新しいターミナルパネルを開き、そこで再実行してください。詳しくは macOS のローカルネットワークアクセスを参照してください。

言語を選ぶ

設定 → 外観 → 言語を開き、英語、韓国語、日本語、簡体字中国語から選びます。変更はすぐに反映され、次回の起動時にも引き継がれます。

切り替わるのは Kiln 自体の画面表示だけです。ターミナルの出力、ファイル名、コード、コミットメッセージ、エージェントへのリクエストは元の内容のままです。以前のバージョンからインストールしている環境では、言語を選ぶまで韓国語で表示されます。

前へはじめに次へワークスペースと作業

文档入门

安装与更新

在 macOS 或 Windows 上安装 Kiln，打开第一个工作区，让应用保持最新，并选择界面语言。

一条命令即可安装 Kiln，也可以从 GitHub Releases 下载。安装后 Kiln 会自动更新，更新时不会打扰正在运行的终端。

系统要求

平台 要求
macOS 搭载 Apple Silicon 的 Mac，macOS 11 或更高版本。构建已通过公证。
Windows x64 或 ARM64 上的 Windows 11。构建暂未进行代码签名。

目前不提供 Intel Mac 和 Linux 构建。Windows 10 未经测试。

在 macOS 上安装

使用安装脚本

在终端中运行：

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | sh

脚本会下载最新的 Apple Silicon 稳定版，先校验发布校验和、Developer ID 签名、应用包标识和 Apple 公证，再安装到 /Applications。如果已经装有 Kiln，脚本不会动现有安装；升级请改用 Kiln → 检查更新。

要安装到其他位置，设置 KILN_INSTALL_DIR：

curl -fsSL https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.sh | KILN_INSTALL_DIR="$HOME/Applications" sh

下载应用

  1. 从 GitHub Releases 下载 Apple Silicon 压缩包。
  2. 解压。
  3. 先把 Kiln.app 移到应用程序文件夹，再打开。

在 Windows 上安装

使用 PowerShell 脚本

在 PowerShell 中运行：

irm https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.ps1 | iex

脚本会按设备架构选择 x64 或 ARM64 压缩包，校验发布校验和以及压缩包内的路径和版本，然后：

  • 把 Kiln 安装到 %LOCALAPPDATA%\Programs\Kiln；
  • 在“开始”菜单中添加 Kiln 快捷方式；
  • 把 bin 文件夹加入用户 PATH，以便使用 kiln 命令。

要安装到其他文件夹，设置 KILN_INSTALL_DIR。已有的安装会原样保留。

下载压缩包

也可以从 GitHub Releases 下载与你的架构对应的压缩包。

注意 Windows 构建暂未进行代码签名。通过安装脚本下载不会触发 SmartScreen，用浏览器下载的压缩包则可能触发。只有来自 Releases 页面的压缩包，才应选择更多信息 → 仍要运行。

首次启动

  1. 从“应用程序”或“开始”菜单打开 Kiln。
  2. 点击工作区侧边栏中的 + 按钮（macOS 上为 ⌘N）创建工作区，为它命名并选择项目文件夹。
  3. 直接使用终端，或者选择新建任务，输入请求，选好代理后启动。

这个文件夹可以是单个仓库，也可以是包含多个仓库的父文件夹。工作区、任务和拆分视图如何配合，详见工作区与任务。

在 Windows 上，如果 Kiln 已在运行，再次启动会把现有窗口切到前台，并在其中打开你指定的文件夹。

安装所需工具

Kiln 调用的是你已安装的代理和 GitHub 命令行工具，既不内置这些工具，也不含订阅。请安装并登录你要用的工具：

工具 用途
Claude Code（claude） Claude 任务
Codex（codex） Codex 任务
Antigravity（agy） Antigravity 任务。请用 Google 提供的安装程序安装。
gh GitHub 功能

Kiln 会在 PATH、~/.local/bin、/opt/homebrew/bin 和 /usr/local/bin 中查找 agy。在 Windows 上，Claude Code 和 Codex 以原生 Windows 程序运行，数据保存在 %USERPROFILE%\.codex 和 %USERPROFILE%\.claude。

Claude Code 和 Codex 账户在设置 → 账户中登录；macOS 上的 Antigravity 在设置 → 账户 → Antigravity 中登录。在 Windows 上，请在终端中运行 agy 登录 Antigravity。详见账户。要查看已安装的 CLI 版本或更新它们，打开设置 → 账户 → CLI 更新，详见对话与更新。

更新 Kiln

更新不会中断正在运行的终端会话。

macOS

Kiln 会自动检查更新，并通过 Sparkle 更新对话框安装。要手动检查，选择 Kiln → 检查更新，或者使用设置 → 关于中的更新控件。自动检查可以在设置中关闭。

Windows

Kiln 每天检查一次更新。要手动检查，打开设置 → 关于 → 检查更新，然后选择安装并重新启动。替换任何文件之前，Kiln 会先验证下载的压缩包与发布签名密钥是否匹配。正在运行的终端不受影响。

提示 在 macOS 15 及更高版本上，如果某条访问本地网络的命令在更新前就已打开的面板中失败，请新开一个终端面板再试。详见 macOS 上的本地网络访问。

选择语言

打开设置 → 外观 → 语言，选择英语、韩语、日语或简体中文。更改立即生效，下次启动时依然保留。

这只会改变 Kiln 自身的界面。终端输出、文件名、代码、提交信息和代理请求都保持原样。从早期版本升级上来的安装会继续使用韩语界面，直到你选择语言为止。
