---

Kiln은 워크스페이스의 대화를 Claude Code와 Codex 사이에 복사할 수 있습니다. 그래서 한 에이전트가 멈춘 곳부터 다른 에이전트에서 `/resume`으로 이어 갈 수 있습니다. 또한 패널마다 대화를 연결해 두므로, CLI를 업데이트하거나 재시작해도 하던 곳으로 돌아옵니다.

## 워크스페이스 연동하기 {#link-a-workspace}

1. **설정 → 계정**에서 Claude Code 계정과 Codex 계정에 로그인합니다. [계정](accounts.html)을 참고하세요.
2. 사이드바에서 워크스페이스를 우클릭하고 **대화 연동**을 선택합니다.
3. 대화상자의 **최근 대화 수**에 동기화할 대화 개수를 지정합니다. 기본값은 **20**이며, 1부터 4096까지 고를 수 있습니다.

동기화는 워크스페이스마다 직접 켜야 하며, Kiln이 열려 있는 동안 실행됩니다. 워크스페이스 폴더 안이라면 어디서 시작한 대화든 포함되며, Kiln 밖에서 시작한 대화도 마찬가지입니다.

한도는 워크스페이스에서 가장 최근에 활동한 대화부터 셉니다. 오래된 대화도 재개하면 다시 동기화 대상이 됩니다. 한도를 낮추면 나머지 대화는 동기화가 멈추지만, 이미 만든 사본은 계속 쓸 수 있습니다.

연동을 끝내려면 같은 메뉴에서 **대화 연동 해제**를 선택합니다. 이미 만든 사본은 `/resume`에서 계속 쓸 수 있습니다. 워크스페이스를 닫으면 그 워크스페이스의 동기화는 일시 중지됩니다.

연동은 상태 대화상자에 표시된 계정 쌍에 묶이며, 나중에 계정을 전환해도 바뀌지 않습니다.

## 다른 CLI에서 이어 가기 {#continue-in-the-other-cli}

다른 CLI에서 같은 프로젝트를 열고 `/resume`으로 대화를 고릅니다. 연동된 대화는 일반 터미널이든 Kiln 계정 패널이든 각 CLI의 재개 목록에 같은 제목으로 한 번씩 나타납니다.

이전 메시지는 CLI의 일반 대화 화면에 표시되고, 다음 모델 요청에 함께 포함됩니다. Kiln이 따로 모델에 요청을 보내지는 않습니다.

### 넘어가는 내용 {#what-carries-over}

| 내용 | 결과 |
| --- | --- |
| 내 요청과 에이전트의 답변 | 문구, 줄바꿈, 코드 블록까지 그대로 복사됩니다. |
| 대화 이름 | 모든 사본이 같은 이름을 씁니다. 어느 CLI에서 이름을 바꾸든 모든 곳에 반영되며, 가장 최근에 바꾼 이름이 우선합니다. |
| 셸 명령과 파일 편집 | 상대 CLI에 대응하는 도구가 있으면 그 CLI의 도구 기록으로, 없으면 읽을 수 있는 텍스트로 표시됩니다. |
| 이미지 | 유지됩니다. |
| 추론, 제공자 지침, 암호화된 기록 | 복사되지 않습니다. |
| 사용 가능한 도구 정의 | 각 CLI는 자체 도구 설정을 사용합니다. Codex가 도구 정의를 추가해도 메시지와 실행 기록은 계속 연동됩니다. |

기록 속의 도구 호출은 다시 실행되지 않습니다. 문서나 오디오처럼 Kiln이 복사할 수 없는 내용이 있는 대화는, 일부가 빠진 채 완료로 표시되지 않고 실패로 분명히 표시됩니다.

### 동기화 시점 {#when-sync-runs}

워크스페이스에서 에이전트 CLI가 실행 중이면 그 워크스페이스의 자동 동기화는 일시 중지됩니다. CLI가 입력을 기다리는 동안에도 마찬가지입니다. CLI가 종료되어 셸로 돌아가거나 터미널이 닫히면 약 1초 뒤에 Kiln이 다시 동기화합니다. 백그라운드 확인은 이전 확인이 끝나고 60초 뒤에 다시 실행됩니다.

완료된 응답만 복사됩니다. 아직 작성 중인 대화는 10초 동안 바뀌지 않으면 읽어 옵니다.

## Antigravity 대화 {#antigravity-conversations}

연동된 폴더의 Antigravity(`agy`) 대화는 Claude Code와 Codex로 복사되므로, 어느 CLI에서든 `/resume`으로 이어 갈 수 있습니다. 복사는 한 방향으로만 이루어집니다. Kiln은 Antigravity의 파일을 읽기만 하고 쓰지 않습니다.

- 요청, 답변, 도구 호출이 복사됩니다. Antigravity의 추론은 Antigravity에만 남습니다.
- 턴은 Antigravity가 답한 뒤에 나타납니다. 할당량이 바닥난 경우처럼 Antigravity가 끝내 답하지 않은 요청은 5분 동안 변화가 없으면 나타나고, 그 뒤에 Antigravity가 답하기 전에 멈췄다는 메모가 붙습니다.
- Claude Code나 Codex에서 이어 간 턴은 Antigravity로 넘어가지 않습니다.
- macOS에서는 [Antigravity 계정](accounts.html#antigravity-accounts)의 대화도 포함됩니다.

상태창에는 중앙 대화 기록의 사본을 만들 계정이 표시됩니다. 여기에 Claude Code와 Codex만 표시되어도 Antigravity 원본은 수집됩니다.

지원하는 Antigravity 파일 읽기, 단일 파일 교체, 셸 명령은 Claude Code와 Codex의 기본 도구 화면에 표시됩니다. 실패한 도구는 실패 상태로 유지합니다. 알 수 없는 형식은 읽을 수 있는 기록으로 남기며, 복사 중 도구를 실행하지 않습니다.

## 양쪽에서 모두 이어 간 경우 {#when-both-sides-continue}

Kiln이 동기화하기 전에 같은 대화를 두 CLI에서 각각 이어 갔다면, 가장 최근에 쓴 쪽이 기본 기록이 됩니다. 다른 쪽에서 이어 간 내용은 보관된 분기로 남고, 그 CLI의 재개 목록에서는 빠집니다. 상태 대화상자에서 **복구**를 선택하면 그 분기가 모든 CLI에서 별도의 대화가 됩니다.

Antigravity 대화의 사본 쪽이 기본 기록이 되면, 원본은 Antigravity에 그대로 남고 Kiln은 원본을 더 이상 따라가지 않습니다.

### Kiln에서 연동된 대화 열기 {#opening-a-linked-conversation-inside-kiln}

다른 Kiln 패널에서 쓰고 있는 연동된 대화를 새 Kiln 패널에서 열면, Kiln은 이전 CLI를 중지하고 종료될 때까지 기다린 뒤 최종 상태를 동기화하고 새 패널만 엽니다. CLI가 종료되지 않으면 새 패널은 상태를 표시하며 기다립니다. Kiln은 CLI를 강제로 종료하지 않습니다.

> **참고:** 외부 터미널과 다른 앱은 이 인계 과정에 참여하지 않습니다. Kiln에서 대화를 이어 가기 전에 닫으세요.

## 동기화 상태 확인하기 {#check-sync-status}

워크스페이스의 동기화 아이콘을 클릭하거나, 컨텍스트 메뉴에서 **대화 연동 상태 보기**를 선택합니다. 아이콘과 대화상자에는 대기, 진행 중, 확인 필요, 일시 중지 상태가 표시되고, 완료된 대화가 모두 동기화되면 초록색 체크가 표시됩니다.

각 행에는 대화 제목, 그 대화가 있는 CLI, `/resume`으로 이어 갈 위치가 나옵니다. **대화 정보**에서는 각 대화 ID와 실패한 항목의 진단 정보를 복사할 수 있습니다.

경고는 직접 해결할 수 있는 문제일 때만 나타납니다.

| 경고 | 조치 |
| --- | --- |
| 연결된 계정 폴더가 없습니다 | **계정 설정 열기** |
| 저장 공간이 가득 찼거나 쓸 수 없습니다 | **다시 시도** |
| Codex CLI가 없습니다 | 대화를 `/resume`에 등록할 수 있도록 Codex를 설치합니다 |

**무시**를 선택하면 다른 문제가 생길 때까지 배지에 그 경고가 나타나지 않으며, 경고는 *무시한 경고 보기* 아래에 계속 남습니다. 따로 조치할 필요가 없는 상태는 회색으로 표시됩니다. **다시 확인**을 선택하면 바로 새로 확인합니다.

## CLI 업데이트 {#cli-updates}

**설정 → 계정 → CLI 업데이트**를 열면 각 CLI의 설치된 실행 파일과 버전을 볼 수 있고, 확인 가능한 경우 최신 공개 버전도 함께 표시됩니다.

| CLI | Kiln의 업데이트 방법 |
| --- | --- |
| Claude Code | `claude update`. 설정해 둔 업데이트 채널을 유지합니다. |
| Codex | 설치할 때 쓴 Homebrew 또는 npm 설치 프로그램. 그 밖의 방식으로 설치했다면 해당 설치 프로그램이 필요하다고 알려 줍니다. |
| Antigravity | `agy update`. 최신 버전은 Antigravity가 직접 확인하므로 Kiln은 표시하지 않습니다. |

이 페이지에서 CLI를 업데이트하거나, **Codex·Claude Code·Antigravity 자동 업데이트**(기본값: 꺼짐)를 켜서 Kiln이 열려 있는 동안 6시간마다 확인하게 할 수 있습니다. Kiln은 sudo를 쓰지 않습니다.

## 같은 대화로 재시작하기 {#restart-in-the-same-conversation}

패널에서 **… → 같은 대화로 재시작**을 선택하면 지금 대화 그대로 패널을 다시 엽니다. 업데이트할 때마다 이렇게 하려면 **업데이트 직후 같은 대화로 세션 재시작**(기본값: 꺼짐)을 켜세요. 이 옵션을 켜면 업데이트가 설치되고 CLI가 새 버전을 보고하는 시점에 패널의 현재 응답이 중단됩니다. 재시작해도 패널, 레이아웃, 작업 디렉터리, 계정은 그대로입니다. 마지막 요청을 다시 보내거나 도구 호출을 반복하지는 않습니다.

Kiln은 CLI의 일반적인 `Ctrl-C` 순서로 CLI를 중지합니다. CLI가 중지를 거부하면 그대로 실행되게 두고 오류를 표시합니다. 다시 실행한 뒤 원래 대화를 확인하지 못하면 경고를 띄우고 다시 시도할 수 있게 합니다.

### 재시작할 수 있는 패널 {#which-panels-can-restart}

Kiln은 자신이 여는 새 Claude Code·Codex 패널의 대화를 패널마다 추적하며, 두 패널이 같은 폴더를 써도 따로 추적합니다. 패널 메뉴를 열면 CLI 버전과 대화 ID를 볼 수 있습니다. 추적 기능이 생기기 전부터 있던 패널과 일반 셸에서 직접 실행한 CLI는 추적되지 않으므로, 새 에이전트 패널을 여세요.

> **팁:** Codex는 새 훅을 신뢰할지 묻습니다. 추적이 계속 대기 상태라면 Codex에서 `/hooks`를 열고 Kiln 훅을 신뢰한 뒤 다음 메시지를 보내세요. 훅이 비활성화되어 있으면 자동 재시작을 쓸 수 없습니다.

Antigravity 패널은 훅 없이 추적됩니다. Windows에서는 Antigravity 패널에 기록된 대화가 없으므로 자동으로 재시작되지 않습니다.

작업의 터미널이 사라지면 Kiln은 원래 요청을 다시 보내지 않고, 기록해 둔 대화를 재개합니다.
