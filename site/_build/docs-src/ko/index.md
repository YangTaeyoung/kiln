Kiln은 에이전트 작업을 위한 터미널 중심 IDE입니다. 터미널, AI 에이전트, Git, 파일, 데이터베이스를 macOS·Windows용 네이티브 앱 하나에 모아 두므로 작업 전체가 한눈에 들어옵니다.

저장소 하나를 열어도 되고, 프론트엔드·백엔드·공유 라이브러리를 담은 상위 폴더를 열어도 됩니다. 터미널 패널에서 Claude Code, Codex, Antigravity를 실행하고, 내 응답이 필요한 작업을 확인하고, 창을 떠나지 않고 결과를 검토하세요.

## 핵심 개념 {#core-concepts}

### 워크스페이스 {#workspace}

워크스페이스는 폴더에 이름을 붙여 만든 보기입니다. 작업, 터미널 세션, 분할 레이아웃, 보내지 않은 요청을 워크스페이스마다 따로 관리합니다. 한 폴더에 **API 리뷰**, **문서**처럼 워크스페이스를 여러 개 둘 수 있고, Kiln을 다시 열면 각각 따로 복원됩니다. 파일과 Git 기록은 폴더에 속하므로 같은 폴더의 워크스페이스는 모두 이를 공유합니다.

폴더는 저장소 하나여도 되고, 여러 저장소를 담은 상위 디렉터리여도 됩니다. 에이전트는 이 공유 루트에서 작업하고, Git 작업은 선택한 저장소에 적용됩니다. 자세한 내용은 [워크스페이스와 작업](workspaces.html)을 참고하세요.

### 작업 {#task}

작업은 워크스페이스의 터미널에서 돌아가는 일입니다. 직접 쓰는 셸일 수도 있고, **새 작업**으로 시작한 에이전트일 수도 있습니다. 사이드바에는 워크스페이스별로 작업이 나열되고, 각 작업이 보고한 상태가 함께 표시됩니다.

| 상태 | 의미 |
| --- | --- |
| 작업 중 | 에이전트나 명령이 작업 중이라고 보고했습니다. |
| 입력 대기 | 에이전트가 내 답변을 기다리고 있습니다. |
| 완료 | 에이전트가 작업을 마쳤다고 보고했습니다. |
| 실패 | 에이전트나 명령이 실패를 보고했습니다. |

세션이 상태를 보고하지 않으면 Kiln은 터미널 출력으로 짐작하지 않고 열린 세션으로 표시합니다. 유휴 상태의 터미널을 완료된 작업으로 보지 않습니다. 작업을 클릭하면 해당 워크스페이스, 탭, 분할 화면으로 바로 이동합니다.

### 패널과 분할 화면 {#panels-and-splits}

터미널마다 패널이 하나씩 있습니다. 패널 헤더에는 오른쪽으로 나누기, 아래로 나누기, 닫기 버튼이 있습니다. 패널 제목을 다른 패널로 끌어다 놓으면 레이아웃을 바꿀 수 있고, 옮겨도 터미널 세션과 실행 중인 프로세스는 그대로입니다. 자세한 내용은 [분할 화면과 패널 레이아웃](workspaces.html#splits-and-pane-layout)을 참고하세요.

### 인스펙터와 도구 {#inspector-and-tools}

오른쪽 워크스페이스 인스펙터에는 **파일**, **변경**, **GitHub**와 데이터베이스 아이콘이 있습니다. 데이터베이스 아이콘에서는 연결, 테이블, SQL 콘솔을 엽니다. 제목 표시줄의 **도구** 메뉴에는 파일, 검색, 소스 제어, GitHub, 데이터베이스, 원격 연결, 문제가 한데 모여 있고, 무엇을 고르든 현재 작업 옆에 열립니다. 창이 좁을 때는 **작업으로 돌아가기**를 눌러 터미널로 돌아옵니다.

### 세션 데몬 {#session-daemon}

터미널은 별도의 로컬 데몬이 소유합니다. 그래서 Kiln 창을 닫아도 셸과 에이전트는 계속 실행되고, Kiln을 다시 열면 그 세션으로 돌아옵니다. 업데이트할 때도 실행 중인 터미널은 그대로 유지됩니다. 다만 시스템을 재부팅하거나 데몬을 명시적으로 중지하면 창을 닫을 때와 달리 세션이 종료될 수 있습니다. 자세한 내용은 [창을 닫아도 유지되는 세션](terminal.html#sessions-that-outlive-the-window)을 참고하세요.

### 알림 {#notifications}

에이전트와 스크립트는 로컬 터미널 이스케이프 시퀀스나 `kiln activity`, `kiln notify` 명령으로 활동을 보고하고 알림을 보낼 수 있습니다. 이때 프롬프트가 다른 서비스로 전송되지는 않습니다. 알림 센터는 최근 알림을 보관하고 각 알림을 해당 세션과 연결해 두며, 알림을 읽으면 그 세션의 확인 필요 상태가 풀립니다. Windows에서는 에이전트 알림이 Windows 토스트로도 뜹니다. 자세한 내용은 [터미널](terminal.html#activity-and-notifications)을 참고하세요.

## 준비 사항 {#what-you-need}

- Apple Silicon 기반 macOS 11 이상, 또는 x64·ARM64 기반 Windows 11
- 사용할 에이전트 CLI(Claude Code, Codex, Antigravity의 `agy`)와 GitHub용 `gh`. Kiln에는 어떤 에이전트의 구독도 포함되어 있지 않으니, 쓰려는 도구를 직접 설치하고 로그인하세요.

앱은 영어, 한국어, 일본어, 중국어 간체를 지원합니다.
