Kiln はエージェント作業のためのターミナルファースト IDE です。ターミナル、AI エージェント、Git、ファイル、データベースを macOS と Windows 向けの 1 つのネイティブアプリにまとめるので、作業の全体をいつでも見渡せます。

リポジトリを 1 つだけ開くことも、フロントエンド、バックエンド、共有ライブラリをまとめた親フォルダーを開くこともできます。ターミナルパネルで Claude Code、Codex、Antigravity を動かし、対応が必要な作業を把握して、結果のレビューまでウィンドウを離れずに進められます。

## 基本概念 {#core-concepts}

### ワークスペース {#workspace}

ワークスペースは、フォルダーに名前を付けて開くビューです。作業、ターミナルセッション、分割レイアウト、未送信のリクエストはワークスペースごとに保持されます。1 つのフォルダーに **API レビュー**と**ドキュメント**のように複数のワークスペースを作ることができ、Kiln を開き直すとそれぞれが個別に復元されます。ファイルと Git 履歴はフォルダーに属するので、同じフォルダーのワークスペースはすべてこれらを共有します。

フォルダーには、1 つのリポジトリも、複数のリポジトリを含む親ディレクトリも指定できます。エージェントはその共通のルートで作業し、Git 操作は選択したリポジトリに対して実行されます。詳しくは[ワークスペースと作業](workspaces.html)を参照してください。

### 作業 {#task}

作業とは、ワークスペースのターミナルで動いている処理のことです。直接操作するシェルの場合もあれば、**新しい作業**で開始したエージェントの場合もあります。サイドバーにはワークスペースごとに作業が並び、各作業が報告した状態が表示されます。

| 状態 | 意味 |
| --- | --- |
| 作業中 | エージェントまたはコマンドが処理中だと報告しています。 |
| 入力待ち | エージェントが回答を待っています。 |
| 完了 | エージェントが完了を報告しました。 |
| 失敗 | エージェントまたはコマンドが失敗を報告しました。 |

状態を報告しないセッションは、ターミナルの出力から推測せずに、開いているセッションとして表示します。アイドル状態のターミナルを完了した作業とは見なしません。作業をクリックすると、そのワークスペース、タブ、分割へすぐに移動します。

### パネルと分割 {#panels-and-splits}

ターミナルはそれぞれパネルに表示されます。パネルヘッダーには、右に分割、下に分割、閉じるの各操作があります。パネルのタイトルを別のパネルにドラッグすると、レイアウトを組み替えられます。移動しても、ターミナルセッションと実行中のプロセスはそのまま残ります。詳しくは[分割とパネルのレイアウト](workspaces.html#splits-and-pane-layout)を参照してください。

### インスペクターとツール {#inspector-and-tools}

ワークスペース右側のインスペクターには、**ファイル**、**変更**、**GitHub** と、接続・テーブル・SQL コンソールを扱うデータベースアイコンがあります。タイトルバーの**ツール**メニューには、ファイル、検索、ソース管理、GitHub、データベース、リモート接続、問題がまとめて並び、選んだものは現在の作業の横に開きます。ウィンドウが狭いときは、**作業に戻る**でターミナルに戻れます。

### セッションデーモン {#session-daemon}

ターミナルは、独立したローカルデーモンが管理しています。Kiln のウィンドウを閉じてもシェルやエージェントは動き続け、Kiln を開き直せばそのセッションに戻れます。アップデートしても、実行中のターミナルは維持されます。一方、システムの再起動やデーモンの明示的な停止はウィンドウを閉じるのとは違い、セッションが終了することがあります。詳しくは[ウィンドウを閉じても続くセッション](terminal.html#sessions-that-outlive-the-window)を参照してください。

### 通知 {#notifications}

エージェントやスクリプトは、ローカルのターミナルエスケープシーケンスか、`kiln activity` コマンドと `kiln notify` コマンドで、アクティビティを報告したり通知を送ったりできます。どちらの方法でも、プロンプトが外部のサービスに送られることはありません。通知センターには最近の通知が残り、各通知は対応するセッションにひも付いています。通知を読むと、そのセッションの要確認状態が解除されます。Windows では、エージェントの通知が Windows のトースト通知としても表示されます。詳しくは[ターミナル](terminal.html#activity-and-notifications)を参照してください。

## 必要なもの {#what-you-need}

- Apple Silicon 搭載 Mac の macOS 11 以降、または Windows 11（x64 / ARM64）。
- Claude Code、Codex、Antigravity（`agy`）のうち、使うエージェントの CLI と、GitHub 用の `gh`。Kiln にはエージェントのサブスクリプションは含まれていません。使うツールは各自でインストールし、ログインしておいてください。

アプリの表示言語は、英語、韓国語、日本語、簡体字中国語に対応しています。
