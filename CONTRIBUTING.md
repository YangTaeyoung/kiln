# Contributing

Start with the [development guide](docs/development.md) and [AGENTS.md](AGENTS.md).
Small, focused pull requests with a clear user-facing problem are easiest to review.

- Preserve terminal sessions, unsaved work and existing configuration.
- Include relevant tests and screenshots for visible changes; use synthetic data.
- Explain what you verified and what remains unverified.
- Keep README concise and place detailed guides under `docs/`.
- Do not commit credentials, user configuration, terminal logs or private captures.

Report reproducible issues with the Kiln version, macOS version, relevant actions
and sanitized logs. Agent subscriptions and external services are separate from Kiln.
