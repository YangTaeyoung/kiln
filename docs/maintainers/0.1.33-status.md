# 0.1.33 release verification

Verified on 2026-10-15 (macOS Apple Silicon).

- Source: `1459345160db8b535004afb200323c78358c1cef`; [PR #11](https://github.com/YangTaeyoung/kiln/pull/11). Exact-source [CI 38723234454](https://github.com/YangTaeyoung/kiln/actions/runs/38723234454) passed both macOS and database-server jobs. PR #11 merged as `36e8e65039e786a5dad755e1fe3e9d500843cee4` with the identical source tree.
- Linked conversations are kept as one canonical history per conversation with one native session in every namespace (both CLIs, default and connected account folders). The most recently active side wins a divergence; the other side is archived and restorable. Legacy copies of the same conversation are recorded by migration and archived by the regular check.
- A fresh-context review of the branch reported seven Important findings; each was fixed with a test that failed first: newest-side selection after incremental reads, Claude title sidecar reverting a rename, restore after a later rewrite, one failing restore or import record stopping every scan, migration archives never retried, interrupted scans corrupting the hub, and projection writes lost by a CLI holding its transcript open (now appended in place). Three Minor findings were re-graded and fixed: a false divergence after a display-equal continuation, scan-level warnings without action or Ignore, and per-scan Codex name requests (now only after the Codex state database or title index changes).
- Measurements (release build, synthetic): one new turn in a 212 MB Claude history synchronizes in about 0.2 s (1.42 s before), 317 MB Codex in about 0.16 s (1.13 s). An idle check of 301 conversations in two namespaces takes 13–16 ms with no Codex requests. A read-only check of 279 local histories (6.4 GB) parsed in 13 s with no errors.
- Installed CLIs in isolated homes against a loopback model endpoint: Claude Code 2.1.300 and Codex 0.162.1 each resumed the other's projection with the full history; the hub ingested both continuations; each CLI then resumed its own original after Kiln appended the other's turn in place.
- Local validation: `cargo test -p kiln --lib conversation_sync` (104 passed) and the CI-equivalent macOS suite (24 steps).
