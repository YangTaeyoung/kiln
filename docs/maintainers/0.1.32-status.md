# 0.1.32 release verification

Verified on 2026-10-15 (macOS Apple Silicon).

- Source: `161ac8c8f7eb7cc3aef11f5979c1e48d2de96da0`; [PR #10](https://github.com/YangTaeyoung/kiln/pull/10). Exact-source [CI 38692008633](https://github.com/YangTaeyoung/kiln/actions/runs/38692008633) passed both macOS and database-server jobs. PR #10 merged as `14f6a7f3bfa2bc6c298139c42d9f84fa4a4856ee` with the identical source tree.
- On the owner's 0.1.31 (6K display at 60 Hz, agents working) the sync worker averaged about 4.5% CPU (0.1.30: about 45%). The GUI used about 25% CPU and 12% GPU and its main thread spent 91% of samples waiting for the next drawable, so it was redrawing continuously; WindowServer (24% GPU) and DisplayLink (13% GPU) composited each frame. Recording `Context::repaint_causes` in an isolated build traced the continuous redraw to the 33 ms progress-indicator repaint.
- 0.1.32 selects tabs, workspaces, sidebar tasks, panels and terminals when the primary button goes down, keeps one frame in flight instead of two, repaints progress indicators every 100 ms while focused and skips a per-frame repository inventory search. An isolated app with one running command redrew 60.2 times per second with the previous interval and 16.0 with this release. A unit test fails when press selection is replaced by click selection.
- Local validation: the CI-equivalent macOS suite (24 steps).
