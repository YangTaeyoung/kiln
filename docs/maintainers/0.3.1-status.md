left-aligned completion, provider author vectors, and readable expanded tool code.

actual copy commands, and bound highlighting to 256 KiB/2,000 lines per block while

reused; unknown logs remain plain text.

integration tests and rendered input tests are separate proof. GUI return still
waits for natural CLI exit; active work and background helpers are never killed to
make a presentation switch possible.

The four site agent images are 2x native component render illustrations with
