# Kiln 0.1.11 verification

This record separates source tests, rendered fixtures and public distribution.
Version 0.1.11 is published. The local review app is intentionally left running;
the owner will update through the official feed.

## Scope

- Native pane movement, local/aligned divider scope, whole-board snapping,
  keyboard resizing, cancellation and session-preserving persistence.
- S3, FTP/FTPS and SFTP file browsing/transfers/editing; SSH config discovery and
  SSH terminal launch; direct Codex/Claude launch. S3 includes explicit saved AWS
  profile, default credentials and manual-key modes.
- Background official-CLI browser sign-in with isolated credentials and saved
  profiles; cancellation and normal GUI termination cleanup.
- Consolidated table-edit dialog using the existing schema prepare/apply guards.
- Synchronized redraw timeout and hosted PTY reader/reconnection recovery.
- Smaller red menu-bar notification/attention indicator.

## Verification

Source tests completed on 2026-10-06 and 2026-10-07, using isolated configuration and sockets:

| Area | Result |
| --- | --- |
| Application | 180 unit (4 opt-in ignored), 40 GUI (1 opt-in ignored), 1 portable-icon test passed; 15 native AppKit IME cases passed |
| Pane layout | Native egui/isolated PTY harness passed, including both missing-bar T arms, cancellation and session identity |
| Direct launch | Revised integration passed using both child processes' physical working directories; first remote CI failed the earlier terminal-text assertion |
| Terminal recovery | 39 daemon tests and native/hosted PTY recovery integration passed |
| Agent accounts | 52 library tests and 1 UI test passed; 16 localized waiting/code captures reviewed |
| Database | 64 library/schema/UI/completion/SQLite tests passed |
| Remote files | 34 library/UI, 1 cancellation and 1 production async UI integration passed; 6 loopback protocol tests passed before the AWS-profile revision |
| Localization | 8 checker tests passed; 1,998 messages and 1,894 literal UI keys validated in four languages |

Designer and developer-workflow review found and corrected table-action wording,
Japanese account-header overflow, duplicate login actions, authentication-child
cleanup on GUI exit, and the missing-bar T-junction hit region. The initial S3
form review was withdrawn after user feedback: clipping checks had not established
acceptable hierarchy or workflow. Independent hostile designer and DX reviewers
subsequently passed the redesigned form, authentication paths and provider icons.
Remote review includes 192 form, 16 file-list and 16 connection-list fixtures.
Table dialogs include 24 fixtures, four languages and both themes at 130% scale.

Native CUA subsequently exercised the first candidate's isolated app: new-task
menu, split-right, remote connection form/advanced/cancel, and the empty account
add/cancel form. No real cloud operation or authentication was started. A fresh
native candidate then exercised asynchronous discovery using synthetic AWS files,
displaying both profiles and applying the selected profile's region. Native text
input did not reach the form and coordinate input returned `noWindowsAvailable`;
native save/reedit was therefore not observed. A separate integration binary
compiled the remote library without `cfg(test)` and passed actual production
discovery, selection, text editing, save/reload, cancel and default-mode reedit
through egui input events. It uses a memory credential store and no injected scan
results. The actual menu-bar dot and manual divider dragging were not observed.
Engine tests and AppKit IME tests do not establish these unobserved native paths.

The portable icon test includes S3, FTP and SFTP identities at five pixel scales
in both themes without host icon fonts. It checks the official S3 green background
and white bucket, painter-order stability, visibility and distinct provider marks.
The binary-distribution license collector includes the bundled AWS source notice
and the repository's third-party notices. A second remote CI run exposed two
agent-icon tests that still queried the pre-refactor texture-cache key. Both
lookups were synchronized with the shared painter; the five-DPI, mesh, size,
three-surface identity and animation assertions remain intact. The account
52-test suite and settings integration passed locally after the correction.
The corrected source passed remote CI. Subsequent native review exposed a
repeated remote-dock title missed by standalone fixtures. The panel now relies
on the host title; an embedded-dock GUI regression passed across four languages,
two themes and 720/1,100-point windows. Native AX confirmed a single title and
the retained add/import/more actions. Screenshot observation after this change
was avoided because the preceding native automation call stalled for hours.
The runtime source at `2fbe4e5` passed its full CI. The final versioned source
`7bb44d3d557effc6f065e21b47a18c8617579a8c` also passed [its complete CI](https://github.com/YangTaeyoung/kiln/actions/runs/37563596138).
The local review candidate already used version 0.1.10. The owner chose to
update through the published feed rather than replace the running app directly,
so the public release uses 0.1.11; the bundled and feed versions must be higher
than the installed candidate. No local GUI, daemon or PTY is stopped for this step.

Distribution was completed on 2026-10-07. Follow the
[release runbook](releases.md) and [remote fixture contract](remote-files-verification.md).

No production bucket, remote filesystem or real agent-account login is changed
by the automated tests. Emulator/server coverage does not prove every provider
policy. The original reported Codex freeze was not uniquely traced to the
reproduced missing redraw-ending marker.
