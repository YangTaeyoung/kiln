# Kiln 0.1.23 verification

Adds opt-in Claude Code ↔ Codex native conversation continuations, pinned account
namespaces, per-conversation progress, connection state and completion indicators.

## Source checks

- Application library: **225 passed, 7 ignored**. The synchronization suite has
  **11 passing tests**, plus two explicitly invoked native-fixture helpers.
- GUI/session integration: **45 passed, 1 ignored**. Generated terminal review
  captures were excluded from the source change.
- `cargo check --locked -p kiln`, `cargo test -p kiln-git`, `git diff --check`,
  and localization validation passed. The catalog contains **2216 messages**
  across four languages and **2022 literal UI keys**.
- Synchronization tests cover exact text and visible native item round trips,
  bidirectional additions, loop suppression, independent branches, cached and
  restarted scans, partial writes, compacted Claude history, UTF-16 project path encoding,
  unsupported attachments and versions, pinned
  namespaces, symlink rejection, crash-plan recovery, destination collisions,
  progress transitions, completion and error UI, and opt-in settings persistence.
- Rendering checks captured the actual egui completion/paused/error states.
  Progress notifications are bounded and throttled. Filesystem work stays on a
  worker, and cancellation does not wait on file IO on the UI thread.

## Installed CLI checks

Used **Codex 0.162.1** and **Claude Code 2.1.296**, only owned temporary roots,
synthetic transcript text, dummy API keys and a loopback mock inference server.

1. The production Rust adapter generated native transcript fixtures.
2. Each installed CLI resumed its fixture and sent the exact original user and
   assistant text, including multiline/code content, in its next inference request.
3. The CLIs appended a new mock response. The production parser read those native
   additions and the engine published both opposite-provider continuations.
4. Native interactive `/resume` showed the imported sessions. Selecting them
   displayed the user and assistant turns in the normal CLI transcript UI.
   Claude's picker was also checked with an untouched synthetic copy, separately
   from the noninteractive SDK-origin continuation used for inference inspection.

This validates CLI display, persistence and request history independently.
It does not validate paid-provider inference, cross-provider tool execution,
attachments, Desktop/cloud sessions, future CLI formats, or personal histories.
Open sessions are not hot-rewritten: users select a newly published continuation.
