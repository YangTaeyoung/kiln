# 0.1.31 release verification

Verified on 2026-10-15 (macOS Apple Silicon).

- Source: `56dc08b5af5e9da3eec950d069a0c8a62b12ca0f`; [PR #9](https://github.com/YangTaeyoung/kiln/pull/9). Exact-source [CI 38669906121](https://github.com/YangTaeyoung/kiln/actions/runs/38669906121) passed both macOS and database-server jobs. PR #9 merged as `2301089b6b7ad2a0d67b250f5f04ce652dc1a908` with the identical source tree.
- After the owner updated to 0.1.30, the sync worker stopped restarting but still averaged about 45% CPU. Scans run every three seconds, and sampling attributed about 78% of the worker's busy time to publishing native links, which searched every linked group once per conversation. Tab focus, panel close and split results could also appear up to one second late because the frame that applied them was drawn only on the next idle timer.
- 0.1.31 draws a follow-up frame after state-changing input or queued actions, computes linked groups and their destinations once per scan, and shows conversations continued separately in both CLIs as kept rather than failed. On a synthetic state shaped like the owner's (1,215 entries, largest group 241) the work after each scan measured 1.2 s on 0.1.30 and about 20 ms with this release. Randomized tests compare the new grouping and published links with a per-conversation reference search.
- Local validation: the CI-equivalent macOS suite (24 steps) including 304 application tests (13 opt-in probes excluded), daemon tests with `KILN_PTY_HOST=0` and GUI tests.
