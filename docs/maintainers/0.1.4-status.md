# Kiln 0.1.4 verification

## Behavior and review

Workspace task rows and panel headers now share the detected agent identity.
Both show the real 18pt Codex or Claude Code mark while idle, waiting and working.
Working adds a separate fixed 24pt activity ring. Brand color remains visible in
unfocused panels and does not replace the state label or waiting/error indicators.
Title positions and button geometry remain fixed across animation frames.

The macOS process resolver follows only exact known Kiro bridges into a unique
inner shell, checking parent lifetime, controlling tty and foreground process group.
It ignores background agents. Confirmed shells/editors and failed lookups clear
stale OSC identity and inferred activity. Explicit integration state is preserved.
See [architecture](../architecture.md#foreground-agent-identity).

- Application library: 154 passed, 4 intentionally ignored.
- GUI and real-session integration: 34 passed, 1 documentation generator ignored.
- Foreground process identity: 3 passed, including a real nested-PTY bridge fixture,
  background agent exclusion, Codex/Claude switching, shell return and editor jobs.
- GUI assertions require separate 18pt branded meshes in both sidebar and header,
  including while agent-colored progress arcs are present.
- Initial idle snapshots and GUI reconnects identify agents without earlier spinners.
- Git integration suites, compile and whitespace checks passed.
- Localization: 1,750 messages, four languages, 1,710 literal UI keys validated.
- Independent hostile design and DX source reviews passed. Design review regenerated
  and inspected narrow 180pt/wide 300pt rows in light and dark themes.
- A read-only local probe identified four existing real wrapped agent sessions:
  two Codex and two Claude Code. No inputs or signals were sent to those sessions.

## Observation boundary

Renderer/PTY fixtures are synthetic, not captures of private user terminal output.
The real-agent probe verifies process identity, not a live installed GUI screenshot.
At archive verification the installed app was 0.1.3; it subsequently updated to
0.1.4 during final checks. The live daemon also reports the current 0.1.4 build,
and all original five shell PIDs remain alive. The installed UI's on-screen icon
appearance was not captured or independently observed. No manual app replacement
or real-session termination was performed, and no temporary test app was installed.
