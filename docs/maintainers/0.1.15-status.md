# Kiln 0.1.15 verification

This release adds multiple named workspaces for one directory, a single Tools
entry point, SSH configuration selection, and native OCI/GCS/R2 profile connections.
See [workspaces](../workspaces.md), [remote files](../remote-files.md), and
[object storage](../object-storage.md) for the user paths and provider limits.

## Research and independent review

[Transmit's connection guide](https://help.panic.com/transmit/transmit5/servers/)
and its actual Quick Connect screenshot informed the compact protocol selector
and provider-specific form. [Cyberduck connection profiles](https://docs.cyberduck.io/protocols/profiles/)
informed provider defaults and keeping endpoint overrides under Advanced.
[cmux's workspace commands](https://cmux.com/docs/custom-commands) document names
and working directories as separate workspace properties. Kiln keeps directory
contents shared while isolating terminal identities, layouts and drafts.

Separate hostile source and rendered-flow reviews checked narrow layouts,
four languages, both themes, saved profile identity and workspace input/undo
isolation. Review found an R2 move that could silently change storage class.
Native moves now reject unsupported classes or SSE-C, explicitly upload Standard
objects as Standard, and confirm the destination's class before deleting the source.
Ordinary uploads retain the provider's bucket-default behavior.

## Local verification

- Application changes: 190 library tests and 43 GUI tests passed; five opt-in
  library cases and one documentation screenshot regeneration were ignored.
  Direct terminal launch and the parent-workspace tool workflow each passed.
- Final remote source: 74 library tests plus AWS, SSH, native object-profile UI
  and cancellation integrations passed (78 total). Six live-protocol fixtures
  remained opt-in. OCI/GCS/R2 operation tests used synthetic CLIs and loopback HTTP.
- Git/GitHub input scope: 15 GitHub UI cases and one commit-input isolation case passed.
- Localization: 2,047 messages and 1,925 literal UI keys validated in four languages;
  eight checker tests and four network-privacy script tests passed.
- Native object-profile UI used production asynchronous discovery, deliberate
  profile choice, save and re-edit. It used private metadata files and an
  in-memory credential store, with no real HOME credentials or cloud operations.
- Same-directory workspace tests checked independent session IDs, layouts,
  requests, checkpoint restoration and closing one without ending another.
  Minimum-size dialogs were reviewed in four languages and both themes at 130%.

The final remote tests additionally cover symlinked profile files, OCI configuration
fallback precedence, relative source paths, inherited credential override removal,
owned CLI process-group cancellation, atomic local downloads, incomplete success
responses, source-generation checks and R2 storage-class preservation.
`git diff --check` passed. Private captures are not committed or release assets.

## Boundaries

No real AWS/OCI/Google/Cloudflare account, production bucket, SSH host or database
was authenticated or mutated. Fixtures do not establish live account permissions.
Native R2 moves retain the documented concurrent-writer window and plain-object
restrictions; larger or unsupported objects require S3-compatible mode.
The owner's installed Sparkle update/relaunch and another Mac's UI remain unobserved.
The owner requested publication and will update the installed app independently.
