## User update boundary

The owner explicitly requested publication to test automatic updates. Accordingly,
`/Applications/Kiln.app` was left at 0.1.0; it was not manually replaced. Its bundle
identifier, Sparkle public key and feed URL match 0.1.1. Existing sessions were not
terminated. Open **Kiln → Check for Updates…** to exercise the published update.

Native UI automation previously returned `Sky Computer Use native pipe startup
failed`. Actual macOS menu clicks/alerts and this 0.1.0 → 0.1.1 relaunch have not
been observed. Do not claim that the user's update finished until it is verified.
Follow [native updater validation](updater-validation.md) for isolated fixtures;
do not stop the real daemon or shell/agent sessions. Future fixes require a higher
version; follow the [release runbook](releases.md) and preserve the signing keys.
