Published on 2026-10-20 at 07:12:02 UTC: [v0.2.3](https://github.com/YangTaeyoung/kiln/releases/tag/v0.2.3). Version 0.2.2 was prepared but never published; its changes ship in 0.2.3.

- [PR #16](https://github.com/YangTaeyoung/kiln/pull/16) merged as `fd602bccfd62cac0949ee2b9d71560fa0d6d24d0`, whose tree equals the PR head `d1d2ce3` that passed macOS, Windows x64, Windows ARM64 and database CI ([39377208810](https://github.com/YangTaeyoung/kiln/actions/runs/39377208810)). Notarization Accepted: `389e2b51-4928-48e2-917a-4cb464693b87`. The x64 CLI reported 0.2.3 under emulation. The VM's user `Path` and Start-menu shortcut were restored and its existing installation was left in place.
- All six draft assets matched local SHA-256 digests before publication. Anonymous downloads of the public assets passed checksums and Ed25519 signature checks; both latest feeds matched the verified feeds.
- The public macOS installer succeeded in an isolated folder (staple and Gatekeeper accepted, binary equal to the public archive); its second run left the app unchanged. In the VM, the public `install.ps1` installed 0.2.3 ARM64 into a fresh folder with matching files, its second run changed nothing, and the user `Path` and shortcut were restored afterwards.

The owner's installed app and running sessions were not replaced or stopped. The in-app update to 0.2.3 is the owner's step. Windows executables remain unsigned with Authenticode; archive update signatures are verified separately.
