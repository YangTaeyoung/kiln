# Kiln 0.1.3 verification

## Source and behavior

- Library: 152 passed, 4 intentionally ignored.
- GUI/session integration: 34 passed, 1 documentation-image generator ignored.
- Native AppKit: 15 explicit callback cases passed. Unpatched winit 0.30.13
  failed on the first case: a Korean commit followed by a question-mark command
  callback delivered no question mark. Patched code preserves it as normal input.
- Native egui-winit cancellation regression passed. Git integration suites passed.
- Localization: 1,750 messages in four languages, 1,710 literal UI keys validated.
- `cargo check`, whitespace and release-script syntax checks passed.
- Independent hostile design review and DX review passed after addressing
  waiting-to-idle identity loss and modifier-shortcut suppression.

The [winit patch record](../../vendor/winit/KILN-PATCH.md) identifies the exact
upstream base, source delta, license, regression command and removal condition.
Of the copied upstream files, only the macOS view implementation differs.
CI includes the hidden-window native regression as well as existing checks.

Idle/waiting task rows use Claude Code or Codex marks in a fixed slot. Running
rows keep the agent-colored animation. An isolated real-PTY test verifies both
agents' OSC tokens, marker-free Codex idle, approval blinking, and return to idle.
Agent inference uses exact foreground names or known leading OSC tokens. A
previously observed identity survives the same title body/process/session;
it is cleared when those change or the session exits. First observation of an
unmarked idle title behind an unidentifiable wrapper remains unknown; the app
must not guess an agent from ordinary task-title words. This cache is not durable.

The menu companion loads a dedicated transparent template at 18pt, instead of
shrinking the Dock tile. A PNG regression checks transparent corners/opening
and enlarged symbol bounds. Narrow 180pt/wide 300pt rows and light/dark themes
were rendered and reviewed. Unread-dot behavior is preserved.

## Observation boundary

The native test exercises production WinitView callbacks on AppKit's main thread,
with a deterministic test-only IME driver. The system Korean input source,
physical typing latency and candidate-popup interactions were not manipulated
or observed. The real PTY test proves byte delivery, including `한?`, without
proving physical input-method behavior. A live installed-menu capture and
owner-driven update/relaunch are likewise separate checks.

The installed 0.1.2 app and real background sessions are preserved for Sparkle
update verification. Temporary native probe windows are hidden and their
processes exit. No additional installed app is created for these tests.
