# Kiln 0.1.16 verification

This release adds reusable object-storage authentication profiles and bucket
catalogs, safe single-table SELECT editing, caret/selection query execution,
and bounded Zsh command suggestions. It also refines remote connection forms,
empty states and the Tools icon. See [object storage](../object-storage.md),
[query results](../query-results.md), and [shell completion](../shell-completion.md).

## Research and independent review

The interaction references are linked in those guides: Transmit/Cyberduck for
connections, DataGrip for query execution/results, Kiro for shell suggestions,
and each provider's official bucket-list API. Separate hostile source and rendered
reviews covered row identity, catalog changes, optimistic updates, private shell
metadata, request ordering, credentials, keyboard behavior and narrow layouts.

Rendered review caught excessive form height, a bucket selector clipped above
the footer, and duplicate remote headings in the hosted panel. Authentication
edit/save sections now collapse, the bucket chooser stays visible above the fixed
footer, and the empty-state heading describes its state. Shell review additionally
caught completion state surviving hidden-tab foreground/process transitions;
exit/replacement/Zsh departure now invalidate it, while a fresh request arriving
before the foreground monitor is preserved. Both themes were reviewed at actual
small icon sizes and 100/136-point terminal popup heights. At 100 points, the
selected row remains visible while adjacent rows or help can scroll out of view.

## Local verification

- Application: 196 library tests and 44 GUI tests passed. Five opt-in library
  fixtures and one public screenshot regeneration remained ignored.
- Portable icons: both tests passed, including the actual 14-point Tools button
  and small wrench/gear/inspector comparisons in both themes.
- Remote: 85 library tests plus AWS, SSH, native object-profile UI and cancellation
  integrations passed. Six live-protocol fixtures remained opt-in. A subsequent
  focused form test passed all 12 provider/theme/width cases with the bucket
  selector fully inside its clip and above the save footer. Final GUI tests
  verified the single remote heading and named actions in four languages. The final
  provider-selector fixture passed 20 consecutive runs across all 16
  language/theme/width combinations and 960 actual provider transitions, followed
  by a full 85-test remote library pass.
- Database: 41 library tests, nine SQLite result-edit tests, and two real query
  editor/grid workflows passed. Disposable PostgreSQL 17.11, MySQL 8.4.11 and
  MariaDB 11.4.13 each passed the server fixture with explicit connection URLs.
  This is separate from the earlier invocation without URLs, which skipped server
  work and was not counted as coverage.
- Protocol/daemon: 62 daemon and four protocol tests passed. The real daemon/Zsh
  completion round trip passed; accepting a candidate did not execute it, stale
  requests were rejected, native Tab remained available, and a non-Zsh foreground
  program's completion metadata was rejected. Final application message-sequence
  tests covered individual/list snapshots, exit, process replacement and outgoing foreground
  changes without an intervening paint.
- The complete Git package regression suite passed. Localization validated 2,146
  messages in four languages; eight checker and four network-privacy script tests
  passed. `git diff --check` passed.

All cloud credentials, bucket catalogs and HTTP/CLI operations used synthetic,
owned fixtures or an in-memory credential store. No live cloud-account ACL or
provider deployment was tested. SELECT editing supports only the documented
single-table/direct-column subset. MySQL's same-second, identical-DDL recreation
identity limitation is documented in [query results](../query-results.md).
Recovered edits are review-only; no saved UPDATE or write capability is replayed.
Shell suggestions support newly integrated Zsh sessions and a bounded set of local
contexts, not arbitrary installed-command help parsing or every shell.
