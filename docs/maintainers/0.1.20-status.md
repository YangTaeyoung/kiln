# Kiln 0.1.20 verification

Includes the [0.1.19 account recovery](0.1.19-status.md) implementation plus
[automatic usage updates](account-usage.md).

## Source verification

- `kiln-accounts --lib`: **77 passed** with isolated credential stores and fake
  CLI processes. Covers all-account repeated background cycles without settings,
  worker shutdown, retry delays, new-token retry, repeated failure preserving
  last-good data, deletion during a slow request and persisted check timestamps.
- Both CLI fixtures prove an external global login cannot be attributed to a
  different saved profile; a changed runtime identity fails closed.
- Real loopback HTTP fixtures exercise GET/no body, no redirect forwarding,
  Retry-After, private-error redaction and oversized chunked responses.
- Provider parsers validate actual Codex window durations, nullable Claude
  windows and above-100-percent exhausted quotas.
- Actual GPU account-card captures fit 420px and 130% scale in all four languages.
  Percentage/reset text is separated and long reset labels truncate with a hover
  value. Captures contain fixture identities and remain outside Git.
- Localization validates **2,184 messages** in four languages and **1,999**
  literal UI keys. `git diff --check` passed.
- Independent hostile review found an active-global credential attribution issue;
  it was repaired and regression-tested. Final source and four-language GPU
  capture re-review found no remaining P1/P2 issue in this scope.
- No real account tokens, Keychain entries or provider APIs were used in tests.
  The owner's installed app, sessions and live daemon were not replaced/stopped.

Full source [CI](https://github.com/YangTaeyoung/kiln/actions/runs/38267842619)
passed on attempt 2 at the immutable release source. Attempt 1 failed the
quick-open test's four-frame asynchronous settle assumption; the unchanged
standalone tests passed 5/5. Version 0.1.21 replaces that assumption with a
bounded wait for the reopened unfiltered results while retaining the selection
and Escape assertions.
