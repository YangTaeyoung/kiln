# Kiln 0.1.18 verification

This release adds per-panel conversation identity, optional CLI updates and exact-conversation restart, plus persistent account configurations. See [CLI updates](../cli-updates.md) and [accounts](../accounts.md).

## Verification

- Application library: 210 passed, five opt-in fixtures ignored, including independent update/restart options and prevention of replaying a restored task's original request.
- Accounts library: 60 passed, including refresh-token preservation, private-file fallback, pending reauthentication, failed Apply rollback and logout without restoring old tokens.
- GUI integration: 45 passed, one public screenshot-generation fixture ignored.
- Direct agent/SSH launch integration: passed, including physical working directory, native IME input and restored launch specifications.
- Installed Codex 0.162.1 and Claude Code 2.1.296 accepted the new launch and exact-resume flags in `--help` mode using isolated configuration directories. This checks argument parsing only, not live hook trust or provider authentication.
- The owned update fixture exercises Codex through a verified synthetic npm installation and Claude through its synthetic updater. Two accounts in the same folder retain distinct conversation UUIDs, configuration paths and panels; both receive new PTY sessions after update and confirm their original UUIDs.
- Independent hostile source review: PASS after fixes for legacy rotation, package-manager ownership, UI-thread version probes, callback ordering and restored-request replay protection.
- Additional exit-path review found no confirmed blocker: [Codex 0.162.1](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/tui/src/chatwidget/interaction.rs#L520) interrupts active work and quits when inactive, with its double-press experiment disabled. [Claude's official controls](https://code.claude.com/docs/en/interactive-mode#general-controls) describe interrupt, clear and exit behavior; its exact 2.1.296 Ctrl-C timing and all live modal/tool states were not exercised. Kiln retains the bounded exit timeout rather than force-killing an agent.
- Git library and integration suites: 137 passed, one opt-in fixture ignored.
- Localization catalog: 2,174 messages validated in four languages.

These fixtures do not authenticate real provider accounts or install a real CLI update. Provider revocation, expired sessions and keyless Claude Console profiles still require their official authentication flow. Existing untracked shells are not automatically instrumented or restarted.
