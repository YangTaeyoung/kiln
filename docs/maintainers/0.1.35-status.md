Verified on 2026-10-15 (macOS Apple Silicon).

- Source: `44a41ac0c3700e58e46129bf1703c0a7aa0258c4`; [PR #13](https://github.com/YangTaeyoung/kiln/pull/13). Exact-source [CI 38745859720](https://github.com/YangTaeyoung/kiln/actions/runs/38745859720) passed both macOS and database-server jobs. PR #13 merged as `7f50c14bd87166bf1b0df81477ac26cec3a27cb0` with the identical source tree.
- The owner reported tool records still looking broken in a Claude Code view of a Codex conversation. 0.1.34 converted only shell commands and kept turns synchronized earlier as labeled text. This release writes native records wherever the other CLI can show them:
  - Claude Code: parallel `Bash` calls for a multi-command Codex program; native built-in tools in another Claude Code account; `name(summary)` text with a `⎿` result for tools Claude Code does not define (it hides such tool uses).
  - Codex: a `McpToolCall` cell for every non-shell call.

  Kiln-written copies made earlier, which hold only Kiln's records, are written again once after ten minutes unchanged. The old session is archived and recoverable.
- A fresh-context review reported five Important findings. Fixed with tests that failed first:
  - the idle condition was bypassed on checks without delays;
  - copies continued in their CLI, and Codex Desktop imports, were rewritten;
  - a failed archive failed the conversation;
  - readable text dropped input fields.

  A regression for trailing whitespace after a command result was fixed the same way. Accepted boundary: a multi-command record in Claude Code that loses Kiln's annotation reads as separate calls.
- Installed CLIs in isolated homes against a loopback model endpoint, with resume views rendered through a terminal emulator:
  - Claude Code 2.1.300 showed "Listed 1 directory", "Listed 1 directory, ran 1 shell command", "Read 1 file" and `js(Open the heading)` with a `⎿` result. Its next request carried two parallel `tool_use` blocks with their matching `tool_result` blocks.
  - Codex 0.162.1 showed "Ran ls -la", "Called claude_code.Read", "Called codex.js", "Ran pwd" and "Failed (exit 1) ls (all)".
- Local validation: `cargo test -p kiln --lib conversation_sync` (123 passed) and the CI-equivalent macOS suite (24 steps).
