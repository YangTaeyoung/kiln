# Kiln 0.2.6 release verification

Published on 2026-10-21 at 02:22:28 UTC: [v0.2.6](https://github.com/YangTaeyoung/kiln/releases/tag/v0.2.6).

## Source and checks

- [PR #22](https://github.com/YangTaeyoung/kiln/pull/22) merged as `19d9d13addb66cbeadc64ec8db9ae51de703dbaa` after macOS, Windows x64, Windows ARM64 and database CI passed ([39528624745](https://github.com/YangTaeyoung/kiln/actions/runs/39528624745)). The PR carries the version and release notes; tag `v0.2.6` points to the merge commit.
  - On the first attempt, the Windows x64 terminal job failed in `same_directory_named_workspaces_create_choose_restore_and_close_independently`: the shell received the test's command without its first character (`rintf`). The job passed when it was run again.
- The owner's conversation store was read in place, without copying, before the fix:
  - The original Codex session of one conversation was waiting in `pending` (7,749 messages). The canonical history held 2,224 messages in the form of a Codex Desktop import and shared 155 messages with the original.
  - Two more conversations had originals continued after their canonical history. One of them extends the canonical history by 1,457 messages.
  - With 0.2.6, all three originals become their namespace's session again.
- The inactive Claude account was a profile without a runtime folder, whose only login was Kiln's saved one. Its re-login stayed staged (`pending_login`).
- Test results:
  - `cargo test -p kiln --lib`: 378 passed.
  - `cargo test -p kiln-accounts --lib`: 127 passed, 3 opt-in tests ignored.
  - The two new conversation-sync regression tests and six of the seven new account tests failed before their fixes.
