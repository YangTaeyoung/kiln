# Kiln 0.1.7 verification

## Scope

The workspace inspector now includes a compact database tab alongside Files,
Changes and GitHub, reusing the existing connection browser and database tools.
Database selection survives closing/reopening and restoring the workspace.

Generated terminal ordinals are removed from workspace task names and the trailing
qualifier. Folder distinctions, agent branding, activity and user-authored numbers
remain. The automatic focus-layout policy is unchanged in this release.

The daemon no longer reports a hard-coded dark default background to palette-aware
terminal applications. The GUI sends its displayed foreground, background, cursor
and ANSI colors before creating sessions, after reconnecting and on theme changes.
Protocol 4 appends the palette message without moving the Hello/Upgrade variants.
Existing postcard session-restore structures are unchanged.

## Boundaries

Codex 0.160.0 caches startup colors and does not query them again on an ordinary
redraw. This fixes a newly started Codex; it does not recolor an already running
Codex or restart an agent automatically. Application-authored RGB is preserved.
See [the versioned Codex source](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/tui/src/terminal_palette.rs#L166).

The daemon uses the default dark palette until a GUI publishes its selected palette.
This is not a complete rewrite of OSC dynamic-color parsing or restoration.
Other-Mac post-release color and menu-icon observation remain unverified.
