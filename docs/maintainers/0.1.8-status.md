# Kiln 0.1.8 verification

## Scope

SQL completion uses asynchronous metadata from an existing connection pool,
current-statement table/alias context and dialect-specific common keywords and
functions. It inserts identifiers without executing SQL. See
[Database tools](../databases.md) for usage and the catalog/session boundary.

## Source verification

- Database library: 23 passed, including self joins, nested CTE shadowing,
  schema-qualified exceptions, PostgreSQL identifier folding and escaped quotes.
- SQL GUI: 7 passed. Real SQLite metadata, insertion, undo/redo, mouse selection,
  dismissal/reopening, modified Enter, IME event replay, selected text, schema
  refresh, DDL invalidation, same-ID connection replacement and disconnect state.
- Actual isolated PostgreSQL 16 and MySQL 8.4: table/column metadata and SQL
  editor insertion passed. Their backend suites passed 5 and 4 tests respectively.
  Server checks use disposable local containers; the default no-URL tests skip
  server paths, rather than establishing server coverage.
- Database integration: SQLite 8, splitter 11, config store 1, UI smoke 6,
  light-theme rendering 1 and 100,000-row grid performance 1 passed.
- Application: 158 passed, 4 intentionally ignored. GUI/real PTY: 39 passed,
  1 documentation generator ignored. Git integration passed.
- Normal shutdown/restart close-preference regression: 10 consecutive local passes.
  The harness now invokes the real eframe shutdown hook and asserts the saved
  pane/session matches live state before rebuilding the app. Dropping a harness
  alone omits the forced checkpoint and is not a normal application shutdown.
  This does not establish crash-recovery coverage.
- Localization checker: 1,774 messages in four languages, 1,731 literal UI keys.
- Independent hostile design and developer DX reviews: scoped PASS after fixing
  stale connection candidates, CTE/alias inference and truncated-name inspection.

Rendered checks cover light/dark themes, Korean/English/Japanese/Chinese,
720-point width and a 420-point split at 130% scale. Two long, common-prefix
column names can be distinguished by their full hover tooltips. Captures stay
local and contain only synthetic SQLite fixtures.

## Boundaries

This is metadata-backed common SQL completion, not a complete SQL semantic
language server. CTE/derived projections, every extension function signature and
console-only TEMP/ATTACH/USE/search_path state are not inferred. Explicit schemas
avoid guessing ambiguous persistent table names. Completion never initiates a
reconnection after an explicit disconnect.

IME checks replay egui events; WGPU renders verify the popup. Native macOS input,
VoiceOver and an installed-device Sparkle relaunch are not claimed by these tests.
No production daemon, agent or terminal session was stopped for verification.
