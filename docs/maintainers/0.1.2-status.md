# Kiln 0.1.2 release verification

Published October 5, 2026 (KST): [Kiln 0.1.2](https://github.com/YangTaeyoung/kiln/releases/tag/v0.1.2).
Runtime source and immutable tag: `07b89287fe63720db7026ac18289d1d06dee167b` / `v0.1.2`.
Existing published versions and their archives are unchanged.

## Input defect and validation

Two cancellation paths were verified in source: the native bridge discarded
winit's Disabled event, and terminal preedit survived blur/hidden tabs. A rendered
window-blur regression failed on the old terminal code and passed after the fix.
The owner's exact preceding action was unknown; no native event trace was captured.

- Application library: 149 passed, 4 intentionally ignored.
- GUI/session suite: 34 passed, 1 documentation-image generator ignored.
- Native bridge: its real State handler regression passed. Disabled becomes empty
  Preedit, never Commit; subsequent Commit is preserved.
- Real isolated PTYs verify preedit stays local, committed Korean bytes arrive
  once, normal typing/Backspace/Enter/Escape remain ordered, cancellation writes
  nothing, and switching tabs does not restore or transfer old composition.
- Rendered tests verify character offsets become terminal columns, Korean and
  combining-mark caret geometry, normal foreground over dim placeholders, and
  unchanged glyph sizing between composing and committed terminal text.
- Already-owned focus is not requested again: egui's request_focus unconditionally
  interrupts native composition. Intentional clicks and actual transfers cancel
  the local overlay. Hidden-view invalidation uses viewport-local pass numbers.
- Independent design and DX review passed the cancellation and rendering change.
- The missed 0.1.1 light PR header snapshot was reviewed and corrected. The light
  Git UI snapshot test then passed without snapshot-update mode.
- Localization coverage, cargo check and git diff checks passed. Tests preceded
  the version-only bump where applicable; the final 0.1.2 build completed.

The [vendored native bridge patch](../../vendor/egui-winit/KILN-PATCH.md) records the
upstream revision, narrow source delta, removal condition and regression command.
Both licenses are retained and included in the bundled third-party acknowledgements.
