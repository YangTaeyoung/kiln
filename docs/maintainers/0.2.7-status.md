# Kiln 0.2.7 release verification

Published on 2026-10-21 at 05:25:59 UTC: [v0.2.7](https://github.com/YangTaeyoung/kiln/releases/tag/v0.2.7).

## Source and checks

- [PR #23](https://github.com/YangTaeyoung/kiln/pull/23) merged as `bf9871c457009f18d4a092c5de89366f19994fbe` after macOS, Windows x64, Windows ARM64 and database CI passed ([39546105000](https://github.com/YangTaeyoung/kiln/actions/runs/39546105000)). Tag `v0.2.7` points to the merge commit, whose tree equals the PR head.
- The owner's conversation store was read in place, without copying:
  - The Claude Code copy of the long Codex conversation held about 38 MB of message content. Claude Code counted 5,508,476 tokens; four automatic compactions reduced that only to 4,715,401 before Claude Code stopped with "Autocompact is thrashing".
  - Codex's own compaction records carry encrypted summaries (`compaction.encrypted_content`), so no summary text can be transferred.
  - Claude Code's error notice (`isApiErrorMessage: true`, `stop_reason: stop_sequence`) was copied to the Codex original as an assistant answer, together with the request before it.
- Test results:
  - `cargo test -p kiln --lib`: 381 passed, twice in a row. In the first full run, the unrelated `agent_runtime::linked_conversation_without_a_transfer_accepts_prompts_and_compaction` failed once under parallel load; it passed in five isolated runs and two full runs.
  - New regression tests cover the error notice, the boundary of a long history, an append beyond the context limit, and the rewrite of oversized copies. The error-notice test fails without its fix.
- Claude Code 2.1.306 in an isolated home, against a loopback model endpoint, with a 1.5 MB synthetic copy written by the new renderer:
  - The session resumed without compacting.
  - The next request carried 25 messages (380 KB): the boundary summary first, and no answers from before the boundary.
  - Kiln's parser read the continued file back as the whole history plus the new turn.
