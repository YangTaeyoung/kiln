# 0.1.30 release verification

Verified on 2026-10-15 (macOS Apple Silicon).

- Source: `b05a2ae8280c18d46405aec29949e27154c3d51a`; [PR #8](https://github.com/YangTaeyoung/kiln/pull/8). Exact-source [CI 38662776096](https://github.com/YangTaeyoung/kiln/actions/runs/38662776096) passed both macOS and database-server jobs. PR #8 merged as `8aa04b3a62e6fe975257aa1a5ba41cec718765ee` with the identical source tree (`69a940c`).
- After the owner updated to 0.1.29, the GUI measured about 200 MB (down from 3.2 GB) and all PTY hosts survived the update, but `kiln sync-worker` stayed near 100% CPU and restarted every 10–30 seconds, each time starting two `codex app-server` readers. Its saved cache held 22 failed conversations (linked histories that diverged) and 55 snapshot-retirement retries; with a two-minute retry cap their 796 MB and 480 MB histories were re-read continuously. Each launch also re-read every linked history because the GUI reset the worker cache for its initial configuration.
- 0.1.30 retries a failed conversation when it or a linked history changes, or after an hour, applies the same rule to snapshot retirement, saves worker results when Kiln closes, and keeps them across configuration changes. A new regression fails on 0.1.29: an unchanged diverged pair is not re-read after the retry delay and is re-read once the peer changes.
- Local validation: 301 application tests (13 opt-in probes excluded) and 48 GUI tests (one documentation screenshot ignored).
