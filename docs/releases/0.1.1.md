# Kiln 0.1.1

- Choose Korean, English, Japanese or Simplified Chinese in Settings. Language
  changes apply immediately; bundled CJK fonts keep text readable on every Mac.
- Open Settings from the menu-bar icon or **Kiln → Settings…** (`⌘,`).
- End background sessions from the menu-bar menu after reviewing the affected
  sessions. New sessions and the daemon are preserved.
- Fix a crash when closing the last panel or tab in a workspace. Kiln keeps the
  workspace open with a fresh terminal; other workspaces remain running.
- Recognize Claude Code's active title animation, so running Claude tasks show
  a spinner in the sidebar, tab and panel header without manual hook setup.
- Distinguish running agents with orange Claude and blue Codex spinners across
  the sidebar, tabs and panel headers. Waiting and errors retain their own icons.
- Keep terminal glyphs intact when changing languages and refresh existing diff
  titles. Settings navigation adapts to longer translated labels.

See [language and native menus](../localization.md) for details.
