# Kiln 0.1.29

- Make conversation sync idle when nothing changed. A failed or waiting
  conversation, including a continued copy, is checked again after 30 seconds,
  then 1 and 2 minutes, instead of re-reading its whole history every few
  seconds. A transcript still being written waits until it has been unchanged
  for 10 seconds; handovers and **Check again** still check immediately.
- Run conversation scans in a separate `kiln sync-worker` process, so reading
  large histories no longer grows the app's memory. Updating an existing linked
  conversation also parses it fewer times, and one Codex metadata reader is
  reused instead of starting a new one for every scan.
- Keep the interface responsive: workspace state is saved off the UI thread,
  agents are prepared in the background, terminals no longer copy every cached
  glyph each frame, background tabs stop streaming screen updates, and idle
  animations and timers wake the app less often.
- Start new terminals at the size they are drawn at.
- Keep prompts flowing in linked conversations: a published link alone, a sync
  in progress, or Claude compaction no longer blocks or interrupts the agent.
- Keep Codex capacity retries running when you switch to another app.
- Show a synchronized conversation as complete after its original transcript
  is deleted.
- Offer **Amend** only when it would change the last commit, show paths
  relative to the workspace in the work switcher, and hide the table filter
  before a database connection exists.
