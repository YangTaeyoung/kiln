# Kiln 0.1.15

- Open files, search, source control, GitHub, databases, remote connections and problems from one always-visible **Tools** menu. Switching tools keeps your terminal task intact.
- Select hosts discovered from `~/.ssh/config` in the SFTP form. Host, user, port and key path are prefilled; explicit edits apply to both SFTP and the SSH terminal.
- Connect directly by hostname or IP without creating an SSH alias. Existing saved connections retain their identity and OpenSSH configuration.
- SSH discovery stays read-only and does not execute `Match exec` or authenticate. Connection forms, compact tool navigation and new messages are checked across supported languages and themes.

This release is signed, notarized and delivered through Kiln’s existing Sparkle update channel.
