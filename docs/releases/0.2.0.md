# Kiln 0.2.0

- **Kiln for Windows.** Windows 11 on x64 and ARM64 gets the same workspace as macOS:
  persistent terminals owned by a background service, Codex and Claude Code tasks with
  conversation sync between them, Git, files, databases, remote files and SSH,
  notifications and the background-session companion in the notification area.
  Install with `irm https://raw.githubusercontent.com/YangTaeyoung/kiln/main/install.ps1 | iex`;
  Kiln checks for updates daily and installs signed updates from Settings → About.
  Windows builds are not code-signed yet. See [Windows support](../windows-parity.md).
- Terminals start in PowerShell 7 or Windows PowerShell, which report commands, exit codes
  and the current folder like zsh; cmd, Git Bash and WSL can be chosen.
- Shortcut names in menus, tooltips and settings follow the platform.
- SSH config paths with backslashes are read as OpenSSH reads them.
