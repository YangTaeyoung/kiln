# Kiln 0.3.4

- Fix idle GUI-to-TUI switches being refused when a declared MCP helper is resolved through the conversation profile’s PATH or working folder. Use the saved provider environment, with an MCP-specific PATH override taking precedence, while retaining exact process ownership checks.
- Keep real background work protected during handoff. GUI-to-TUI still waits for work to finish; returning from the native TUI to GUI still waits for normal CLI exit.
- Show a persistent conversation activity strip with an animated indicator, response/tool/waiting/completed states and observed elapsed time. Keep it visible while reading older messages.
- Surface Claude native shell, Monitor and other task events, including live background membership, progress summaries, available run durations and ended-task details. Ambient watchers remain visible without marking the main response as running. Other providers show the tools they report.
- Add a floating Jump to latest action when scrolling up or reading an earlier history window; preserve the unsent draft and resume following the latest messages.
- Read and refresh recent shell/Monitor output from task details without sending a model prompt. Label partial, empty and unavailable output explicitly.
