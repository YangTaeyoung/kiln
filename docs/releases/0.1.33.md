# Kiln 0.1.33

- Keep one conversation, not copies of copies. Each linked conversation now has a
  canonical history in Kiln and exactly one native session in every namespace — both
  CLIs, in the default and the connected account folders — so `/resume` lists each
  conversation once, with the same title, in Claude Code and in Codex.
- When both CLIs continued the same conversation, the most recently active side becomes
  the conversation and the other continuation is archived instead of being reported as
  a failure. **Restore** brings it back as a separate conversation.
- Existing duplicate copies of the same conversation are archived (recoverable) the first
  time Kiln synchronizes after the update; unrelated conversations that share a title
  are kept.
- Titles no longer show CLI command markup or image placeholders, and a rename in either
  CLI becomes the name everywhere and stays after later turns in the other CLI.
- Accept new Claude Code and Codex versions whose records Kiln understands, instead of
  pausing every conversation after a CLI update. Content Kiln does not know pauses only
  that conversation until Kiln updates.
- Warn only about problems you can resolve (a missing account folder, full or
  unwritable storage, a missing Codex CLI), each with an action and **Ignore**; warnings
  clear on their own once resolved. Other states are shown as information without a
  badge.
- Synchronize long conversations faster: only records appended since the last completed
  turn are read and written. One new turn in a 212 MB Claude history now synchronizes in
  about 0.2 s instead of 1.4 s.
- New turns are appended to a transcript in place, so a CLI that keeps it open never loses
  its later records.
- One failing restore, import record or archive no longer stops synchronization; it is
  shown on its own row and retried. An interrupted check resumes without duplicate copies.
- Idle checks no longer ask Codex for the name of every conversation; Kiln asks again only
  after Codex's state database or title index changes.
