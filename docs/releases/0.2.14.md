# Kiln 0.2.14

- Reduce periodic Git work: inactive workspaces pause automatic refreshes, repository status checks run one at a time with spaced starts, and unchanged worktree identities are reused.
- Move periodic agent-handover metadata reads off the GUI thread and reuse unchanged JSON, while retaining exclusive writer leases and retrying interrupted transfers.
- Coalesce output-only redraw requests while preserving immediate keyboard echoes and important events. Keep the existing low-latency presentation mode.
- Recheck daemon versions after reconnection and prevent an older helper from replacing a newer daemon.

These changes reduce verified background work. Physical keyboard or mouse latency and duplicate input still require observation on the affected device.
