# Kiln 0.1.14

Terminal connection recovery now preserves the running shell or agent when a panel's
PTY-host connection is interrupted. Automatic repair has a three-attempt limit;
failed recovery appears in both the panel and workspace task list, with a manual
**Reconnect** action. The action is also available in a running panel's **…** menu.

This release fixes continuously renewed synchronized redraws hiding output, lost
input workers after transport interruption, and input/output lock cycles during
reconnection and panel resizing. A busy panel no longer blocks another panel's frame
publication. All recovery states are localized in Korean, English, Japanese and Chinese.

Recovery repairs the terminal connection; it does not restart agents or send `/resume`.
An internal CLI hang can still require the CLI's own resume flow.
See [terminal recovery](https://github.com/YangTaeyoung/kiln/blob/main/docs/terminal-recovery.md) for behavior and investigation boundaries.
