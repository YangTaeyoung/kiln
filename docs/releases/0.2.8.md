# Kiln 0.2.8

- A Codex conversation continued in Claude Code shows Codex's tool calls the way Claude Code
  shows its own:
  - Shell commands are `Bash` records, also when they ran in another folder (shown as
    `cd FOLDER && …`), ran in parallel, were still running, or came from an `exec_command`
    call.
  - File edits made with `apply_patch` are `Update` records with their diff and line
    numbers, and new files are `Write` records.
  - Other tool results that stay readable text show the command output instead of raw JSON.
- Claude Code copies made by earlier versions are written again once in this form, after they
  have been unchanged for ten minutes.

Windows archives remain unsigned by Authenticode; in-app updates use the existing Ed25519
update signature.
