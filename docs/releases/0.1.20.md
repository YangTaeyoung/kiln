# Kiln 0.1.20

- Refresh saved Claude Code and Codex account usage automatically, including
  inactive profiles, at startup and every five minutes while Kiln is open.
- Show when usage was last checked, keep previous bars after failures and respect
  provider retry delays. Usage checks do not call a model or interrupt sessions.
- Sign in again from a saved profile without deleting it. Keep names, IDs,
  order and history; new credentials wait for **Apply**.
- Keep account controls accessible in narrow settings windows, with Korean,
  English, Japanese and Simplified Chinese translations.

See [agent accounts](../accounts.md) for usage, sign-in recovery and provider
availability boundaries.
