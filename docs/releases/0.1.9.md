# Kiln 0.1.9

Manage database structure without leaving the workspace, and get more dependable
language detection and completion in the file editor.

- **Edit database schemas.** Rename or delete tables, add/edit/rename/drop columns,
  and add or remove ordinary column indexes. Preview SQL, review its target, then
  apply. Table deletion also requires the exact name. Database errors retain input.
- **Inspect indexes clearly.** Separate columns, indexes and DDL sections show
  ordered keys, uniqueness, methods, definitions and available partial/INCLUDE
  metadata. The explorer opens the same actions in existing table tabs.
- **Preserve pending work.** Restored schema forms never replay SQL or approval.
  Changed structures refresh clean views, while unsaved row edits remain protected.
  SQLite rebuilds preserve dependencies and validate foreign keys before commit.
- **Identify file languages consistently.** Filename, extension, shebang and bounded
  content detection share one source. Override the language above the document;
  clean and unsaved files retain that choice across restarts.
- **Complete with or without a language server.** Installed servers provide semantic
  suggestions; local keywords and document words remain available without one.
  Full replacement ranges and additional LSP edits form one undo step. Late responses
  cannot edit a changed document. Narrow popups keep keyboard/wheel selection visible.
- **Fix post-DDL refresh.** SQLite queries refresh schema/statement metadata before
  execution, preventing stale column counts after adding a column from another
  pooled connection. PostgreSQL validates catalogs on the locked DDL connection.

All new controls and application messages support Korean, English, Japanese and
Simplified Chinese. Syntax assets and agent tools remain local.

See [database tools](../databases.md) and [file editor](../editor.md) for usage,
configured language servers and supported operation boundaries.

This release targets macOS on Apple Silicon. UI checks use Kiln's headless renderer;
native installed-app interaction and a live updater round trip are separate checks.
