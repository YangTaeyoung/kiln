# Kiln 0.1.21

- Refresh every saved Claude Code and Codex subscription account in the
  background while Kiln is open, including inactive profiles and when settings
  are closed. Checks start at launch and target a five-minute interval.
- Honor each account's next check time so changing request latency does not skip
  a cycle. Respect provider retry delays and keep the last successful values
  and check time after failures. Usage checks do not call a model or interrupt
  sessions.
- Sign in again from a saved profile without deleting it. Preserve names, IDs,
  order and history; new credentials wait for **Apply**.
- Keep narrow account controls accessible in Korean, English, Japanese and
  Simplified Chinese, and make the asynchronous quick-open regression wait for
  its results before testing Escape.

See [agent accounts](../accounts.md) for usage, sign-in recovery and provider
availability boundaries.
