# Kiln 0.1.16

- Get local shell suggestions for folders, installed commands and common Git, Docker, npm and Cargo commands. Open the themed menu with **Ctrl+Space**; selecting a candidate inserts text without executing it. New integrated Zsh terminals load the feature, while existing sessions and native Tab completion keep their behavior.
- Discover available object-storage buckets after choosing an authentication profile. Select existing AWS, OCI, Google Cloud or Cloudflare credentials, or save multiple named profiles in Kiln for reuse across connections. A single available bucket is selected automatically; larger catalogs remain a choice.
- Simplify remote connections with named actions, compact connection forms, collapsible authentication details and a clear primary save action in light and dark themes.
- Edit supported single-table **SELECT** results directly in the query grid. Changes are staged until Apply, checked against the original row and saved in an exact-one-row transaction. Ambiguous tables, missing row keys, views and computed results remain read-only with a reason.
- Run the SQL statement at the caret by default, or only the selected SQL. **Run all** remains an explicit action.
- Preserve unfinished query-result edits for review after reopening, protect submitted writes from accidental closing, and use a recognizable wrench for the Tools launcher.

Detailed behavior and boundaries: [shell completion](../shell-completion.md), [object storage](../object-storage.md), and [query results](../query-results.md).
