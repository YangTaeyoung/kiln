# Kiln 0.1.25

Workspace conversation sync now reads existing histories across verified older CLI
versions and preserves embedded images in native Claude Code and Codex continuations.

- Fix false failures when a Claude session changes working directories, tool search
  emits a tool reference, or Codex decorates a user message with image labels.
- Stream large logs and retain original messages across recoverable Claude
  compaction boundaries, including stable completed checkpoints from active logs.
  Summaries never replace available original history.
- Select the latest 20 actual conversations per workspace, excluding empty CLI
  sessions and local-command-only records. The old initial selection is refreshed once.
- Include native picker titles so long initial prompts remain discoverable in
  Claude Code `/resume`.
- Verify all portable text and image bytes before publishing a native copy, and
  retire obsolete echo bookkeeping without deleting native sessions. Recognize
  Codex native imports of Kiln copies to prevent repeated cross-app transfers.
- Keep results and layout stable during background polling. A single scrollable
  list shows failure reasons immediately, with expandable diagnostics and a manual
  check action. Missing or unsupported attachments never count as a complete sync.

Use the workspace context menu to link conversations, then select the latest
copy with `/resume` in the other CLI. Already-open CLI sessions keep their history.
See [conversation sync](../conversation-sync.md) for supported formats and limits.
