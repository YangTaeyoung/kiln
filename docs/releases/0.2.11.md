# Kiln 0.2.11

- Choose how many recent conversations each workspace keeps synchronized (20 by default). Copies across agents count once; older histories remain available.
- Reduce background synchronization work with cached discovery, unchanged-alias reuse and retry delays, and a pause after each scan.
- Speed up Claude Code history reconstruction after compaction while preserving original message order and attachments.
- Keep cancelled scan results from interfering with newer synchronization work.

This release reduces verified synchronization costs. System-wide keyboard or mouse latency has not been established as a consequence of those costs.
