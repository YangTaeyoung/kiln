# Kiln 0.1.28

- Keep one canonical native conversation per CLI and account namespace when
  switching between Claude Code and Codex. New completed messages append to the
  same IDs while preserving existing history and attachments.
- Transfer a linked conversation exclusively inside Kiln: stop the previous
  agent, sync its final saved checkpoint, and reopen the requested agent. Other
  conversations keep running. Conflicts and incomplete exits stay visible.
- Archive superseded generated snapshots only after provenance and full-history
  checks; retain divergent branches and original conversations.
- Show each linked conversation once in workspace sync status, including its
  most urgent pending or failed endpoint.
- Preserve interrupted requests and recorded tool output during handover.
- Keep native resume titles aligned, including resumed imports and whitespace
  normalization, and retain the readable tool history added in 0.1.27.
- Discover and continue compressed Codex histories without treating their original
  JSONL paths as missing or creating a second native conversation.
