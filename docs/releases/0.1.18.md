# Kiln 0.1.18

- Track the exact Codex or Claude Code conversation for each newly opened agent panel. Inspect its conversation ID and CLI version in the panel menu.
- Check CLI versions and opt into background updates from **Settings → Accounts → CLI updates**. Optionally restart tracked panels immediately after an update, preserving the original conversation, account and folder.
- Keep saved accounts in separate persistent configuration directories. Preserve CLI token refreshes rather than restoring stale credentials, and roll back failed account applications.

Automatic updates and immediate restart are off by default. Restart interrupts the current response. Codex hook tracking requires review and trust in `/hooks`; manually launched and existing untracked shell sessions are not restarted. Codex package updates require a verified Homebrew or npm installation; custom installations use their own installer. Managed panels keep their original account when a usage limit is reached.

See [CLI updates](../cli-updates.md) and [accounts](../accounts.md) for usage, supported paths and verification boundaries.
