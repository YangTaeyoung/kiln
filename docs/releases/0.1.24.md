# Kiln 0.1.24

Conversation continuity now discovers existing Claude Code and Codex sessions by
explicitly selected workspace folder, including subfolders and ordinary CLI histories outside
Kiln. The initial sync includes the 20 most recent conversations per workspace;
new or modified conversations continue syncing automatically.

- `/resume` copies are available in both default CLI and connected-account folders.
  Codex copies are registered in its native session index before showing success.
- Discovery, empty folders, progress, completion and unsupported histories have
  distinct status feedback. Each destination has a continuation ID control.
- Restarting retains the initial selection; repeated scans do not echo imported
  copies. Closing a workspace pauses its synchronization.

Connect both accounts in **Settings → Accounts**, then right-click a workspace and
choose **Link conversations**. Only selected folders synchronize; the previous
global switch does not automatically enable any workspace. Workspace icons show
progress, completion or errors. Click the icon or choose **View conversation sync
status** for that folder's conversation list. Unlink from the same context menu.

Select the latest copy with `/resume` in the same project; already-open
conversations are not hot-rewritten.
The experimental adapter still supports Codex 0.162.1 and Claude Code 2.1.296 text
transcripts. Unsupported versions, attachments and incomplete histories show a
reason instead of silently dropping content.
