# Kiln 0.2.3

- Keep subscription usage current for Claude accounts that are not in use. Kiln renews an
  idle account's expiring Claude Code login the way the CLI does, under the CLI's refresh
  locks, so its usage no longer stops about eight hours after the account was last used.
- Ask to sign in again when Claude rejects an account's refresh token, and stop its usage
  requests until it signs in. Usage failure notes say how long ago usage was last read.
- Fix Claude usage lookup selecting a different Keychain account from the CLI.
- Decode hexadecimal credential JSON returned by macOS Keychain tools and safely recover
  matching Codex account files.
- Read Codex quotas without forcing token rotation on every settings refresh. The active
  account can use its matching default CLI login when its saved runtime login is unavailable.
- Show an authentication-specific status when a subscription login is missing.

Windows archives remain unsigned by Authenticode; in-app updates use the existing Ed25519
update signature.
