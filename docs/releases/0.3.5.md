# Kiln 0.3.5

- Return an idle Claude Code terminal to GUI by selecting GUI, without manually typing `/exit` or Ctrl+D. A private, per-launch native mod requests Claude’s own exit action only when its prompt is idle and empty and no native task badges remain. Keep the original conversation, account and working folder.
- Defer a pending return while Claude is working, waiting for approval, holding a draft or reporting background shells/Monitors. Select TUI to cancel the deferred return. Keep the single-writer and exact process ownership checks before starting the GUI backend.
- Show Claude’s native next-prompt suggestions as faint text in an empty GUI message box. Tab accepts into the draft, Enter or Send submits, and Esc dismisses. Preserve typed text, attachments, IME composition and native suggestion preferences; never fabricate fallback suggestions.
- Fix native terminal rows in the workspace agent list retaining a generic provider name over the current conversation title. Meaningful custom tab and session names remain preferred.
- Update all four user-guide languages and add localized native suggestion illustrations.

Automatic terminal return requires an available Claude mods bridge, verified with Claude Code 2.1.327. Existing workers keep running their original code during app updates; new native launches from updated workers receive the bridge. Codex, Antigravity and unavailable/disabled bridges keep the normal CLI-exit fallback with an explicit banner.
