# Kiln 0.3.2

- Attach images in Claude Code, Codex and Antigravity conversations with multi-file selection, focused image paste, or a drop on the intended pane. Preview and remove attachments before sending. PNG, JPEG, GIF and WebP are supported, up to eight images and 20 MiB per image.
- Fix idle Claude GUI-to-TUI switching with verifiable SDK-owned MCP helpers. The SDK closes its own clients without disabling MCP settings; unrelated background work is left running.
- Open a fresh Claude conversation in TUI before its first message, using the same native conversation ID without replaying a prompt.
- Interactive agent commands launched through Kiln's registered shell functions can use the joined GUI/TUI tabs while retaining the parent terminal, account and working directory. Select GUI and exit the native CLI normally to continue the conversation. A first native exit without a GUI request returns its exit status to the original shell.
- Preserve unsent shell-attached drafts when their agent exits. The saved conversation can be viewed alongside the original shell without sending work or injecting its draft into a newer conversation.
- Query Windows handoff process identities through native APIs, avoiding repeated PowerShell startup and preserving creation-time and ownership checks.
- Translate handoff errors and align unavailable transitions with the actual runtime state.

GUI/TUI handoff requires confirmed native identity and exclusive provider ownership. Native-only tool cards and image payloads in historical TUI records are not reconstructed. Registered-shell integration and native CLI capabilities still apply; see the [agent guide](https://kiln.melona.cloud/docs/agents.html).
