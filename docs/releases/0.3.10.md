# Kiln 0.3.10

- Reopen workspaces with the tabs, splits, and focused pane you left open, even after a restart.
- Reconnect to running terminals. If a shell has ended, Kiln opens a new one in its last saved folder and displays the recent output.
- Continue Kiln-managed agent conversations in their original panes with the same conversation and unsent drafts.
- On macOS, press Command–Up or Command–Down in a terminal, or hold Command while scrolling over it, to change the terminal font size.
