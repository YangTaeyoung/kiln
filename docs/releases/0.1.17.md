# Kiln 0.1.17

- Browse remote folders directly in the workspace inspector. Saved connections show their bucket or host and current path, with a clear expand/collapse control.
- Keep the main workspace for terminals and opened files. Each remote file gets its own editor tab; navigating folders no longer creates a large directory tab.
- Continue uploads and downloads while the inspector is hidden. Protect active transfers when closing a workspace or quitting, while allowing unrelated panels to close.
- Preserve remote editor drafts and interrupted-operation notices across reopening without replaying transfers. Changed or removed connections cannot redirect an old editor's writes.
- Move existing remote directory tabs into the inspector on reopening, retaining navigation and unfinished file edits.

See [object storage](../object-storage.md) and [remote-file verification](../maintainers/remote-files-verification.md) for behavior and validation boundaries.
