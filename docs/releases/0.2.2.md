# Kiln 0.2.2

- Fix Claude usage lookup selecting a different Keychain account from the CLI.
- Decode hexadecimal credential JSON returned by macOS Keychain tools and safely recover matching Codex account files.
- Read Codex quotas without forcing token rotation on every settings refresh. The active account can use its matching default CLI login when its saved runtime login is unavailable.
- Show an authentication-specific status when a subscription login is missing.

Windows archives remain unsigned by Authenticode; in-app updates use the existing Ed25519 update signature.
