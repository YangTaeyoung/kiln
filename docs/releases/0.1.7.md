# Kiln 0.1.7

- Open database tools directly from the workspace inspector beside Files, Changes and GitHub. The compact database tab remembers its selection when the inspector is reopened.
- Remove generated terminal ordinals from workspace task names and the right-hand label. Meaningful folder names, agent icons and activity still identify tasks; numbers in your own task names stay unchanged.
- Report the displayed terminal foreground, background, cursor and ANSI palette to terminal applications. The selected palette is delivered before a new session starts, and sent again after reconnecting or changing themes.
- Correct the dark composer shown by a newly started Codex in a light Kiln theme. Actual Codex 0.160.0 startup verification covers both light and dark input areas.

The update preserves existing terminal sessions and processes. Codex 0.160.0 caches its startup colors: after updating Kiln or changing its theme, a newly started Codex uses the corrected palette. An already running Codex may keep its previous input-area colors; Kiln does not restart agents automatically or recolor application-authored RGB output.
