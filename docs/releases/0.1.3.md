# Kiln 0.1.3

- Keep Claude Code and Codex recognizable in idle and waiting workspace rows, with distinct agent marks and colors. Running tasks retain their animated indicators.
- Preserve observed Codex identity when its activity spinner disappears or an approval prompt returns to idle; clear it when the session, process or title changes.
- Replace the menu bar's miniature Dock tile with a larger, transparent Kiln symbol. Keep the unread notification dot and automatic menu contrast.
- Fix macOS Korean composition swallowing the next question mark, punctuation or digit. Preserve Enter, Backspace and modifier shortcuts, and prevent duplicate spaces during composition commit.

This release includes native AppKit callback regressions, real isolated PTY input checks, and narrow/light/dark rendering review. Physical input-method timing and candidate-popup interaction still require observation on the installed app.

The Apple Silicon archive is Developer ID signed and notarized. Existing installations can use **Kiln → Check for Updates…**.
