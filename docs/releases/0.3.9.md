# Kiln 0.3.9

- Search slash commands and aliases for Codex, Claude Code, and Antigravity from
  the conversation composer. Commands that open provider dialogs stay in the
  same Kiln pane and can be inserted into the CLI input there.
- Use GUI controls to inspect MCP servers, review changes, copy responses, and
  view background tasks. Codex can rename the active conversation and open the
  workspace file picker from slash commands.
- Windows updates reopen the Kiln window after the previous process exits.
- The [agent guide](https://kiln.melona.cloud/docs/agents.html) describes the
  command palette and provider-specific availability.
