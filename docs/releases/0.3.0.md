# Kiln 0.3.0

Kiln offers native conversations for Claude Code, Codex and Antigravity alongside
the existing terminal experience.

- Choose Conversation or Terminal from New Task and split-panel launch menus.
- Read streamed Markdown, expand real tool results and file diffs, and answer permission requests and questions inline.
- Attach images and compose Korean text without submitting unfinished IME composition.
- Keep the selected CLI account and configuration attached to the conversation. Closing the window preserves its worker, history and unsent draft.
- Recover uncertain delivery as an explicit draft instead of silently sending it again. Restart disconnected conversations with the native session when available.
- Use a compact agent header, integrated composer, consistent launch menu, readable tool cards and notifications above the work surface.
- Codex Stop also requests termination of commands started in the current turn. Unsupported or unconfirmed native termination is reported explicitly; prior background commands are preserved.
- Search provider session settings and commands/skills, with model-dependent effort/mode choices and Claude's independent Ultracode. Requested settings stay separate from native confirmation.
- Run explicit Codex goals, queue, review, compaction, current-turn settings, memory and MCP actions. Open separate conversations for startup options; inherited, managed and terminal-only features keep their native boundaries.
- Prepare supported personal Claude/Codex author assets for private profiles while preserving profile edits/deletions. Prepared or retained assets do not establish native loading or execution.
- Read localized tool/question headers in English, Korean, Japanese and Simplified Chinese while original names, arguments, outputs and diffs remain unchanged.

The official CLI for each provider must be installed and signed in. Provider availability, native permissions and authentication still apply. The terminal presentation remains available for existing workflows.

See [the conversation guide](../agent-gui.md) and [provider coverage](../agent-feature-coverage.md)
for features and provider limits. The [dated verification record](../maintainers/0.3.0-status.md)
separates actual runtime and capture provenance, native permission and Korean IME
limits, platform checks, cleanup and delivery evidence.
