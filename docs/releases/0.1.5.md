# Kiln 0.1.5

- Running shell and agent tasks appear first in workspace history and recent work. Idle agent sessions retain their actual task titles and never inherit a running state from their launch command.
- Split right, split down and close are available directly in panel headers. Narrow splits keep usable controls and move overflow actions into the panel menu.
- Running-process close confirmations offer **Don’t ask again**. The preference is saved only when termination is confirmed and can be re-enabled in Settings. Unsaved file and request warnings remain active.
- Complete missing interface translations across Korean, English, Japanese and Simplified Chinese, including Git sync, workspace context and editor status. New activity notifications follow the selected language after relaunch; older notifications without activity metadata retain their original text.

Validated with isolated PTYs, four-language rendered confirmation dialogs, narrow-panel interactions, settings persistence and unsaved-work protection. Existing terminal sessions are preserved by the normal update flow.
