# Kiln 0.2.15

- Complete Antigravity browser-code sign-in without waiting indefinitely for the CLI to exit. Show code verification and actionable failures, prevent duplicate submissions, and remove copied line wrapping from Google codes.
- Fix Antigravity task launch when an account’s private home differs from Kiln’s configuration directory.
- Use the selected Antigravity account when typing `agy` in a new Kiln zsh terminal, preserving arguments and the current folder, including when Kiro is installed. Version, help and update commands continue to run directly.
- Show Antigravity quota usage and reset times for each model group. Checks run on startup and every five minutes through the official read-only CLI command, require agy 1.1.11 or later, and do not start model turns or spend model quota.

Antigravity account management is available on macOS. Existing running agent sessions keep their original account. Open a new Kiln terminal after updating to use the shell integration.
