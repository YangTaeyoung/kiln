# Kiln 0.1.12

- Fix Claude browser sign-in losing the macOS login Keychain when its configuration
  is isolated. Keep the real home directory for Keychain access while separating
  the new account's configuration, credentials and metadata.
- Accept the official CLI's isolated credential-file fallback and report failed
  Keychain writes instead of treating them as successful saves.
- Add **Settings → Behavior → Privacy → Local Network → Request Access** on
  macOS 15 and later, with a shortcut to Privacy & Security settings.
- Include native network-permission descriptions in all four supported languages.
- Build the menu companion separately and reject colliding executable UUIDs
  before signing, following Apple's application-identity guidance.

The permission request uses Apple's best-effort mechanism; it does not override
macOS privacy settings or claim that access has been granted. Native permission
prompts, the reported Kubernetes connection and actual account sign-in still
need confirmation on the affected Mac after updating.

See the [local-network guide](https://github.com/YangTaeyoung/kiln/blob/v0.1.12/docs/local-network.md)
and [account guide](https://github.com/YangTaeyoung/kiln/blob/v0.1.12/docs/accounts.md).
