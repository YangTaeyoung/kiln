# Kiln 0.2.16

- Open ordinary files, dotfiles and extensionless files from Finder with **Open With → Kiln** on macOS. Open several files together, reuse existing editors and preserve unsaved changes.
- Discover installed CLI commands, subcommands and options automatically from supported local help, including Docker Desktop plugins. Completion uses bounded background probes and a cache, with a generated Docker Engine, Buildx and Compose fallback. No AI account or model connection is required.
- Complete directories for `cd` and directory options, files for file options, local Git branches and package scripts. Continue into nested folders and handle spaces, Unicode, quotes and literal path characters.
- Keep the completion menu beside the cursor inside the terminal pane, with matching fonts, theme and icons. Tab inserts a suggestion; Down selects the menu; Enter runs the original command until the menu is selected.
- Improve DotENV and SSH client/server highlighting, filename and shebang detection, and common configuration formats. Preserve manual language choices and Plain Text mode.

Open a new integrated Zsh terminal after updating to load the new completion bridge. Unsupported shells keep their native completion. Existing terminal sessions continue running.
