# Kiln 0.1.23

- Add opt-in Claude Code ↔ Codex conversation continuity in Settings → Accounts.
  Finished text conversations are copied into native sessions that can be selected
  with `/resume`, including normal user/assistant history and the next model's context.
- Show connection state, overall progress, conversation titles, direction, waiting
  and failure reasons, and green completion checks. Copy continuation IDs directly
  from the conversation list.
- Pin the connected account pair, suppress echo loops, preserve parallel branches,
  and publish new copies without rewriting original or open sessions.

The experimental adapter supports Codex CLI 0.162.1 and Claude Code 2.1.296.
Textual tool records are included; images, attachments and unknown transcript
versions are reported as unsupported. Each completed change creates a new copy;
choose it in `/resume` to switch. See [conversation synchronization](https://github.com/YangTaeyoung/kiln/blob/main/docs/conversation-sync.md)
for setup, progress states, supported scope and storage limits.
