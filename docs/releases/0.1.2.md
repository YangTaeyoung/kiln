# Kiln 0.1.2

- Clear unfinished IME text when composition is cancelled, the window loses
  focus, or a terminal tab is hidden. Previously, old Korean characters could
  remain over an empty prompt's placeholder.
- Preserve native input-source cancellation events and avoid interrupting an
  already-focused terminal during a redundant focus request.
- Position the IME caret and candidate-window anchor using terminal cell widths
  and the input method's active character range. Keep short compositions inside
  the right edge and use normal text contrast over dim placeholders.

IME composition is sent to the terminal only on Commit; cancelled composition is
never sent as input. Automated native-event conversion, rendering and real PTY
regressions cover cancellation, tab switching and single delivery of Korean text.
Physical macOS input-method feel and candidate-popup interaction remain to be
confirmed on the installed app.
