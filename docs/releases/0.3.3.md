# Kiln 0.3.3

- Send follow-up messages with Enter or Send while a response is running. Stop remains a separate control. Claude uses streaming input, Codex steers the confirmed active turn, and Antigravity waits for its current prompt before sending the follow-up.
- Keep model, reasoning effort and mode selectors available during work. Native confirmations still determine effective values. Codex composer choices apply to subsequent turns; its explicit active-turn settings action remains separate.
- Show conversation titles in workspace activity instead of generic provider names, while preserving custom page titles.
- Accept cancellable GUI-to-TUI handoff requests during work and transfer after the existing idle and ownership checks pass. Native TUI-to-GUI still waits for normal CLI exit; this release does not move an active model request between processes.
- Correlate follow-up receipts so an older response or a locally recorded user message cannot falsely confirm a newer send. Rejected or unknown messages remain recoverable without automatic replay.
- Explain settings and every built-in choice in the selected UI language across Claude Code, Codex and Antigravity, including startup and active-turn options, sandbox controls and granular approvals. Keep native identifiers unchanged.
- Replace the raw model-information dump with compact comparison cards: current model first, a concise localized summary, input and reasoning badges, a direct selection action and expandable details.
