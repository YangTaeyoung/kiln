# Kiln 0.2.17

- Keep terminal connections and screens intact when a daemon replacement is delayed or rejected. Automatic replacement is attempted once per daemon and target; use Settings > About > Replace with this version to retry.
- Show upgrade progress only after the daemon acknowledges the request. Match failures to their request, report them once and reconnect only when the connection actually closes.
- Return daemon replacement failures to the CLI, retain the reason in the daemon log and bound the upgrade protocol exchange to five seconds, including partial reads and blocked writes.
- Refresh shared-link previews with a branded Kiln product card and complete Open Graph and Twitter image metadata. Keep real application captures in software screenshots and review localized search metadata across the site.

Existing terminal sessions keep running when the Kiln window closes or updates.
