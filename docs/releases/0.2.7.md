# Kiln 0.2.7

- A long conversation continued from Codex in Claude Code no longer stops at "Autocompact is
  thrashing". Kiln's Claude Code copy now starts the context at a compaction boundary: the
  most recent part of the conversation stays in context, and the boundary's summary lists
  your earlier requests. The whole conversation stays in the transcript. Copies made by
  earlier versions are written again once, after they have been unchanged for ten minutes.
- An error notice from Claude Code (an API error, or a compaction that cannot fit the
  context) is no longer copied to Codex as an answer; your request is.

Windows archives remain unsigned by Authenticode; in-app updates use the existing Ed25519
update signature.
