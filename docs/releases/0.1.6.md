# Kiln 0.1.6

- Use the same Codex and Claude logos in account settings, workspace navigation and terminal headers. Recognized agents retain their logo in task tabs while idle or waiting, with activity shown separately. Ordinary and exited shells remain distinct from agents.
- Keep the selected Kiln theme consistent when macOS changes between light and dark appearance. Buttons, menus and typography no longer switch to an unconfigured system style.
- Make narrow-panel navigation use compact layout controls and a bounded, truncated task selector. Long task titles remain available on hover and cannot push controls outside the window.

The update preserves the existing terminal daemon and sessions. Application and operating-system themes may be selected independently.
