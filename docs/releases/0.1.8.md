# Kiln 0.1.8

- Add SQL completion backed by connected database metadata: schemas, tables,
  columns and aliases, plus common keywords and functions for PostgreSQL,
  MySQL, MariaDB and SQLite.
- Show suggestions while typing, or invoke them with Control+Space,
  Option+Escape or the console's code icon. Use arrows/mouse wheel to browse,
  Tab/Enter to insert and Escape to dismiss. Query execution shortcuts stay separate.
- Preserve undo/redo, quoted and Unicode identifiers, selections and IME
  composition. Candidate details identify tables/types; hover shows full names.
- Refresh metadata after successful console schema changes, allow manual refresh
  for external changes and discard stale metadata after connection replacement.
  Completion does not reconnect explicitly closed connections.
- Keep suggestion panels bounded in small splits, light/dark themes and all four
  UI languages.

See [Database tools](../databases.md) for shortcuts and the catalog/session-local
metadata boundary. CTE/derived projections and every extension function signature
are not inferred. This release preserves existing terminal sessions.
