# Kiln 0.1.0

The first public Kiln release brings terminal sessions, AI-agent tasks and development
tools into one workspace.

- Parent-folder workspaces for tasks spanning several Git repositories.
- Split terminals, task activity, notifications and local session persistence.
- Codex and Claude task launchers with repository context.
- Git/GitHub tools, drag-select squash, cherry-pick and commit removal with review.
- File editing and LSP, search, SQL consoles and database grids.
- Sparkle update checks in the official macOS app.

This release is for **Apple Silicon Macs running macOS 11 or later**. The app UI is
currently primarily Korean. Agent CLIs and GitHub CLI are separate installations.

Download the ZIP, extract it, and move Kiln.app to Applications. See the
[documentation](https://github.com/YangTaeyoung/kiln/blob/main/docs/README.md) for setup.
