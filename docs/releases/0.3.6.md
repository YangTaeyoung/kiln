# Kiln 0.3.6

- Fix GUI return for tracked Claude terminals and older GUI workers that were already running before an app update. Connect a process-specific native bridge without replacing the running CLI or its account profile.
- Preserve ongoing work, native drafts and shell/Monitor tasks until normal return is possible. Confirm cancellation before clearing a pending handoff; retain the same conversation if native exit has already committed.
- Prevent reload shortcuts from being queued into active native work. Require a recognized idle prompt and atomically reject control input when the terminal screen, input revision or process changes.
- Recover a temporary native shortcut after an interrupted app run, preserving concurrent user edits. Resume empty native histories through their exact existing conversation identity.
- Update return-state explanations and the four translated guides.

Late connection to existing workers is supported on macOS with compatible Claude mods. Custom shortcut conflicts, unavailable/disabled mods, other providers and older Windows workers without a verified foreground input route retain normal CLI-exit fallback. Existing processes continue running during updates.
