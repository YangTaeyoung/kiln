# Kiln 0.2.23

- Add API connections to Claude Code and Codex in **Settings → Accounts**. Save a direct API key, gateway, Amazon Bedrock connection, or custom environment variables, then switch to it for new panels.
- Use a gateway such as Sub2API with a Base URL and API key. Claude Code uses the Messages API; Codex uses the Responses API. Both can use a gateway-specific model.
- Keep connection values in the credential store. Existing panels keep their original profile when reopened, and subscription usage checks skip API connections.
