# Kiln 0.2.10

- Kiln runs the Antigravity CLI (`agy`) next to Claude Code and Codex. Start it from
  **New task**, **Open in folder**, the command palette or a workspace's agent request, which
  passes the request as agy's initial prompt. Panels running `agy` show the Antigravity mark.
- Kiln records the conversation an Antigravity panel has open without changing agy's
  configuration, so **Restart in the same conversation** and restarts after a CLI update reopen
  it with `agy --conversation`. CLI updates use `agy update`. Antigravity usage limits show a
  notification with the reset time.
- Antigravity conversations in a workspace linked for conversation synchronization are copied
  to Claude Code and Codex, so you can continue them with `/resume`. Kiln only reads agy's
  files; turns continued in Claude Code or Codex stay there.
- Kiln does not save or switch Antigravity accounts; agy keeps its own sign-in.
- The agent choice below a workspace request fits all three agents in narrow sidebars.

Conversation restart for Antigravity panels is not available on Windows. Windows archives
remain unsigned by Authenticode; in-app updates use the existing Ed25519 update signature.
