# Kiln 0.1.13

- Fix macOS background-terminal attribution by giving newly opened panels their own persistent PTY host. This addresses local-network commands failing in Kiln while working in Terminal.app.
- Preserve existing native sessions, shell PIDs and completed hosted history across mixed-session updates.
- Keep update, resize and close controls responsive when a process stops reading terminal input. Restore input and process monitoring if an update fails.

Install the official app with one command from the [README](../../README.md).

After updating, open a **new terminal panel** and retry the affected command. Existing shells remain available; an update does not restart their processes or repair their old attribution chain. Local-network permission still follows macOS settings.
