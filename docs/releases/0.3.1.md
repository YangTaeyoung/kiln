# Kiln 0.3.1

- Compact agent conversation composer with localized mode names, readable native model choices, discrete reasoning sliders and an independent Ultracode switch in a popover.
- Searchable commands and skills with bounded lists, expandable details and left-aligned keyboard completion. Selecting a command edits the draft without sending it.
- `@` file and folder completion with quoted Unicode paths, background workspace search and provider-native path references.
- Settings organized around editable GUI controls. Noninteractive native inventories are hidden; reset actions and reference details stay in row information menus.
- Same-conversation GUI/terminal switching in the original account and workspace. Handoff requires an idle, exclusive provider process; background work is preserved when switching is unavailable. Returning from the terminal waits for the CLI to exit normally.

Native CLI capabilities, account policy and model availability still apply. Terminal history imported into the GUI preserves text; native-only tool cards and image payloads are not reconstructed by the handoff reader.
