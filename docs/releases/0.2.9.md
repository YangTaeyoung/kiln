# Kiln 0.2.9

- An account you use in Claude Code no longer shows "sign-in required" when Kiln's own copy of
  its login has expired. Kiln keeps a separate login for each account's panels; when that
  copy has expired and Claude Code's own login of the same account is valid, Kiln reads the
  account's usage with Claude Code's login instead of asking you to sign in again.

Windows archives remain unsigned by Authenticode; in-app updates use the existing Ed25519
update signature.
