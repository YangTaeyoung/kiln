# Kiln 0.1.10

- Move panes by dragging their headers. Resize a local segment or an aligned
  boundary, with snapping to halves, thirds and quarters of the terminal area.
  Highlights appear during interaction; Escape restores the previous layout.
- Browse S3, FTP/FTPS and SFTP connections, transfer multiple files, and edit
  remote files. Import SSH aliases and open SSH terminals from the same sidebar.
- Start Codex or Claude directly and add saved agent accounts through browser
  sign-in, without opening a login terminal.
- Open **Edit table** for columns, indexes, DDL and schema changes in one dialog.
- Recover terminal redraws when a synchronized-update ending marker is missing,
  and preserve hosted PTY output across reconnect races.
- Use a smaller red menu-bar indicator for unread notifications and attention.

See the [pane guide](https://github.com/YangTaeyoung/kiln/blob/v0.1.10/docs/pane-layout.md), [remote-file guide](https://github.com/YangTaeyoung/kiln/blob/v0.1.10/docs/remote-files.md),
[account guide](https://github.com/YangTaeyoung/kiln/blob/v0.1.10/docs/accounts.md) and [database guide](https://github.com/YangTaeyoung/kiln/blob/v0.1.10/docs/databases.md).

Remote protocol tests use isolated local servers. Trusted-certificate FTPS and
production cloud-account policies remain outside that coverage.
