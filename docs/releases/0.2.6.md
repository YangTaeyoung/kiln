# Kiln 0.2.6

- Conversation sync keeps your original Codex conversation when Codex Desktop imports one
  of Kiln's Claude Code copies. Such an import no longer replaces the original, so turns you
  continue in the original Codex conversation reach Claude Code again. A conversation whose
  original was replaced this way, and that you continued afterwards, becomes the shared
  history again with the next check; the history it replaces stays a restorable branch.
- Claude accounts you switched away from stay signed in: Kiln renews their saved login before
  it expires, as Claude Code does for the active account.
- Signing in to a Claude account again reads its usage right away, before **Apply**, and
  clears the previous "sign-in expired" note.

Windows archives remain unsigned by Authenticode; in-app updates use the existing Ed25519
update signature.
