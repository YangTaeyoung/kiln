# Kiln 0.1.32

- Select tabs, workspaces, sidebar tasks, panels and terminals when the mouse
  button goes down instead of when it is released, as native macOS tabs do.
  Keyboard and accessibility activation are unchanged.
- Show each frame on the next display refresh instead of queuing one more frame
  ahead, cutting one refresh interval from typing and click feedback.
- Draw the progress indicators of running agents and commands 10 times per
  second instead of 30 while Kiln is focused. With a command running, the
  window was redrawn at the display refresh rate (60 times per second) and is
  now redrawn about 16 times per second, which also lowers WindowServer and
  external-display work on large screens.
- Skip repository-status bookkeeping for repositories that do not need a
  refresh on every frame.
