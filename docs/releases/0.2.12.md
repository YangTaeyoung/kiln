# Kiln 0.2.12

- Add multiple Antigravity Google accounts in Settings → Accounts on macOS. Sign in through the official CLI, import an existing login, rename accounts, and choose the account for new tasks.
- Keep each Antigravity account in its own home and macOS keychain. Existing tasks retain their original account; reauthentication verifies the account identity before applying new credentials.
- Discover conversations from registered Antigravity accounts for read-only synchronization and exact conversation restart.
- Start initial conversation synchronization immediately when no agent is running, and defer automatic synchronization until active agents exit while preserving the selected conversation.

Antigravity account management is available on macOS. Usage quotas and automatic account rotation are not included. Windows continues to use the ordinary Antigravity CLI login.
