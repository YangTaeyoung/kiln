# Kiln 0.1.35

- Tool calls from the other CLI look native in more cases. Claude Code shows Codex
  programs that run several commands as parallel `Bash` calls and keeps its own built-in
  tools (Read, Edit, Write, Grep, …) native in another account. Codex shows every tool call
  from Claude Code as a tool call cell.
- Tools that have no counterpart in Claude Code (such as Codex's browser tool) read as
  `name(summary)` with the input in a code block and the result after `⎿`, without labels or
  call IDs.
- Conversations synchronized by earlier versions are written again once in the new form.
  After a Kiln-written copy has been unchanged for ten minutes, it is archived (recoverable)
  and the CLI receives a new one. Originals and copies you continued in their CLI are never
  rewritten.
